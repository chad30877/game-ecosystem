disable-model-invocation: true

1. 每次訪談開始時，讀取專案的[後續構想](../../../docs/future-ideas.md)，辨識與當前主題相關的未完成項目；由使用者決定是否納入本輪，已明確延後的項目維持延後。
2. 讀取並套用 [grilling](../grilling/SKILL.md) 與 [domain-modeling](../domain-modeling/SKILL.md)，進行訪談及記錄。
3. 訪談中出現延後的構想，或既有構想被納入、完成或放棄時，依後續構想文件的維護方式同步更新。
