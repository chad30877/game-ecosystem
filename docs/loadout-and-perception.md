## 配置與施放

每個物種的四招技能池依正式規格定義，出生取得兩招且欄位順序固定。初始族群以洗牌後的六種組合循環分配，每種組合數量相差最多一；每輪重新洗牌。後代獨立等機率抽取六種組合，不複製親代。

`WorldAction.skillSlot` 使用 `-1`／`0`／`1` 表示不施放／欄位一／欄位二。保留既有 `skill` 名稱入口，但仍檢查個體是否攜帶；指定欄位優先，拒絕時不換招。共用能量、每欄獨立冷卻；衝鋒、攻擊前搖及培育施放期間不能開始另一技能。無效目標、能量不足、冷卻與未攜帶技能均不扣施法成本、不啟動冷卻；日常耗能照常結算。

本任務接上原有 Charge、Cultivate，並將 Shield 移至炎角獸的防禦姿態；苔靈已不具護盾。新增技能名稱可配置及選擇，但效果分別由任務 15–17 實作，目前嘗試會被拒絕。原基本冰箭的減速會由任務 16 分離。

## 感知與動作

朝向以度數表示，0° 朝右、正值逆時針；`turn` 為 `-1`／`0`／`1`，每秒最多 180°，移動與朝向獨立。視野距離沿用 `observationRadius`，角度為朝向左右各 60°，含邊界，不處理遮擋。

`IndividualState.perception` 為不截斷的可變長度觀察，提供物種、世界位置、當前移動速度及可見狀態，不包含個體識別。敵人離開後保留物種與最後位置五秒，移動資訊歸零並標記不可見；各個敵人分別記憶，友軍不保留。世界每步更新記憶，讀取觀察不會延長期限。列依位置排序，不以內部個體編號排序。內部記憶鍵不送給策略或寫入觀察。

ML-Agents 自身向量為 11 維：四向邊界、朝向、能量、兩個技能身分、健康、兩個冷卻。Entities Buffer 的生物列七維為物種、相對位置二維、速度二維、可見狀態及記憶時間；食物列以物種值 0 區分，另外六維為相對位置二維、兩個 0、成熟狀態及剩餘比例。食物只提供觀察半徑內資訊。ML-Agents 需預留張量容量，因此依世界人口、五秒內可能出生數與食物來源上限推算容量，沒有另設附近個體截斷數。世界列表仍為完整資料。動作為四個連續值（移動二維、相對自身的瞄準偏移二維）與四個離散分支（轉向、技能欄位、攻擊、採食）；瞄準偏移乘以世界邊長，仍可輸出世界內任意位置。本次介面語意已改變，舊版工具鏈 checkpoint 不應視為相容的戰術模型。

介面與規則版本更新為 `perception-v1`；舊版模型的輸入／輸出不同，需全新訓練，不能直接續訓。舊版 combat-v1 紀錄仍保留，但不由新版 ReloadRun 重新執行。

## 指定動作與人工核對

場景 `placements` 可指定 `facing` 及兩個技能名稱的 `loadout`；配置必須是所屬物種的不同技能，只於每輪初始化套用。`commands` 新增 `turn` 與 `skillSlot`。沿用原有 `skill`、移動、攻擊及採食入口。

```powershell
./scripts/world.ps1 -Mode build
./scripts/world.ps1 -Mode forage -WorldConfig training/scenarios/world.json -Scenario training/scenarios/flame.json -Visible
./scripts/world.ps1 -Mode forage -Visible -Controller manual
```

第一個場景確認衝鋒與近戰；手動模式用方向鍵移動、Q/E 轉向、S/D 選擇兩欄技能、A 攻擊、空白採食。朝向線與移動獨立；點選個體核對兩欄技能及各自冷卻。新增技能效果尚未實作時，按鍵不應扣施法能量或啟動冷卻。
