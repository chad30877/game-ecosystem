# 分流標籤與執行狀態

| 標籤 | 用途 |
| --- | --- |
| needs-triage | 尚待判定需求與處理方式 |
| needs-info | 缺少必要資訊 |
| ready-for-agent | 規格已明確，可在前置完成後由 agent 執行 |
| ready-for-human | 需要人工處理 |
| deferred | 已決定延後，保留未完成工作與證據，暫不執行 |
| wontfix | 已決定不處理 |

本機任務開始後使用 `claimed`，全部驗收完成後使用 `resolved`。尚有未通過的驗收時保持未完成並記錄原因；不得只因程式可啟動就標為完成。

使用者決定延後的任務改為 `deferred`，並記錄原因、尚缺驗收及後續構想連結；它不代表失敗、放棄或驗收通過。恢復前須由使用者重新排入，依當時環境確認規格、相容性、預算與前置，再改回 `ready-for-agent`；前置完成不會自動解除延後。
