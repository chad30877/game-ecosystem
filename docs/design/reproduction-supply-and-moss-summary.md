# 繁殖供給與果實流轉：共同理解

2026-10-30 彙整。Q1–Q91 的設計與驗收決策已收斂，本摘要待使用者確認共同理解；尚未發佈正式規格、拆分任務或實作。完整取捨與邊界見[訪談紀錄](reproduction-supply-and-moss.md)，其中早期被替換的提案不再適用。

## 目標與範圍

- 將連續食物改為逐顆果實，串起生長、採集、攜帶、交付、進食、掉落與腐爛；親代以送果取代直接轉移飽食度。
- 苔靈透過播種與培育改善有限供給，但空間、果數、週期、壽命及加速上限共同限制產能，不依人口自動增產。
- 接受物種優勢不同、人口波動、衰退或滅絕；不要求等量共存。人口硬上限只作執行保護，碰到上限不能當作自然穩定。
- 保留既有自動繁殖條件與親代飽食代價，不新增存糧准生條件，幼體出生不帶果實。

## 來源、配置與週期

正式世界為 40×40；起始固定十二小、四大，合法布局及階段依種子錯開，至少一處有可採果。起始來源按既有年齡推算階段與果實保存狀態，不重新保鮮；生物起始不攜果。

| 初值 | 小型 | 大型 |
| --- | ---: | ---: |
| 每輪果數（等機會整數） | 2–4 | 5–7 |
| 果實容量 | 4 | 7 |
| 新建後首次成熟等待 | 10 秒 | 15 秒 |
| 每輪結果期 | 30 秒 | 40 秒 |
| 休養 | 20 秒 | 30 秒 |
| 從建立起算壽命 | 120 秒 | 240 秒 |
| 生長圓半徑 | 4 | 5.5 |

- 天然與播種來源共用空間，整個生長圓須在界內、彼此不重疊，休養時仍占地；生物可以穿行。來源類型建立後不變，來源自行生長，不依賴播種者存活。
- 天然補生目標十六處，每十秒最多補兩處；未成熟及休養仍計數，播種不占天然名額，但共用空間與全來源六十四安全上限。兩型都合法時天然小 70%／大 30%，苔靈播種小 80%／大 20%；只容小型就取小型，無空間則等待，不欠額補發或擠掉來源。
- 所有後續新來源均從年齡零、零果實開始；先等待首次成熟，再進入結果期。休養後直接進入下一輪結果，不重走首次成熟等待。
- 每輪先依種子抽一次果數與非線性成熟安排，前疏、中密、後疏並有少量有界擾動；最後一顆在結果期終點成熟。少量果實不強求完整三段疏密。採集或培育中斷不重抽，採走或腐爛不補當輪名額。
- 每顆實際成熟後保存四十秒，最後十秒顯示將腐爛。轉移、放下及培育都不刷新保存；到期與完成同時，先腐爛，未吃完不補營養。
- 即使果實已採光或吃完，來源仍等本輪最後一顆的腐爛期限才休養；期限依實際成熟時刻決定。來源壽命到期則移除來源及未採果實，已採果實保留自身到期時刻。

## 果實操作與負重

| 操作或數值 | 初值 |
| --- | --- |
| 每顆營養／進食 | 飽食 +20／2 秒，吃完整顆才取得，多餘不退回 |
| 採集／拾取 | 1 秒／0.5 秒 |
| 交付／主動放下 | 1 秒／0.2 秒 |
| 採集、拾取、交付距離 | 0.7 |
| 攜帶容量 | 成體 3、幼體 1，正在吃的也占格 |
| 零或一顆／兩顆／三顆的速度 | 100%／90%／80% |

- 三物種與幼體共用食物操作時間。採集、拾取只在實際操作時暫占單顆，不遠端預約整株；同時爭果公平抽選且可重現，已有有效暫占不被後到者重抽。
- 交付限同種，雙方須停下配合；接收者一次接一筆並預留一格，完成才從送方轉至收方。中斷仍在送方，交付不直接增加營養。
- 食物操作及培育均須停下，掃視本身不打斷；主動移動或換互斥行動、目標失效等會中斷。一般受傷或中毒跳傷不強制中斷，但 AI 可選擇應戰或避險。未完成食物操作重新計時，培育的來源進度保留。
- 主動逐顆放下需時間；死亡立即掉落尚未腐爛的全部攜帶果實。地上果實任何物種可拾取，不長成來源，也不刷新保存時間。
- 負重套用走跑與自身衝鋒／疾行速度各一次；普通移動與既有減速相乘，定身仍為零。不增加額外飽食或體力消耗，不拖慢食物操作或培育。
- 安全時偏向裝滿，急需吃、送果與逃生優先。有安全空檔才逐顆放到剩一顆，先放較舊者，每放一顆重判；近身威脅先逃，不回頭補滿。一般換果須有明確用途，不建立地面囤貨循環。

## 進食與幼體照顧

- 自身飽食 ≤65 吃一顆後重判；≤45 自救優先於補貨與送果，避險及既有保護優先序仍適用。
- 規則 AI 主動送果只給自己的幼體；觀察或記憶估計幼體飽食 ≤40 且無果才啟動照顧，至 ≥60、成年或失效停止。親代 ≥50 才開始新交付，≤45 中止先自救，不固定保留一顆。
- 新交付先選可送達且需要食物的幼體，與最低估計飽食相差不超過十的候選再選較近者；已開始有效交付不反覆換目標。持果未知不當成零顆，須依允許資訊確認需求。
- 自用偏較舊但估計吃得完的果實，送果偏較新鮮且估計能完成路程、交付與進食者；只依粗略新鮮度與記憶，不加固定兩秒緩衝。自身危急且無較好選項可嘗試高風險果實。
- 幼體有果先吃，無果且需要、安全時才接收，不打斷進食或逃跑。接收方保留有效操作；多個可接受邀請條件相近時親代優先、再選較近者，同條件公平抽選。

## 播種與培育

- 播種每次魔力 12、冷卻 8 秒、距離 3；AI 魔力 ≥40，無立即食物且估計能等待時飽食 ≥30 可考慮。失敗不扣魔、不啟動技能冷卻，AI 至少隔一秒再嘗試，不以失敗取得隱藏來源情報。
- 自身半徑八內，先取得可用果實，已有未成熟、結果中或休養來源就先利用、培育或探索，不因暫空就追加。沒有這類已知來源，或確認只剩等待腐爛期限的來源，才考慮補種；新播幼株也算。舊情報先確認，滿載又無送果需求時不為花魔力而播種。
- 候選播種中心須在可見施放範圍內，依已知占地、邊界與威脅排除無效點，安全候選以種子抽選；世界作最後合法性檢查。先選點再按合法類型抽大小，不能藉撤銷或重抽偏拿大型；無位置就移動或探索。
- 培育每秒耗魔 6、範圍 1.5，無額外啟動費或冷卻；取消魔力五十開始、二十五停止門檻，付得起即可持續，付不起才結束，恢復後重新評估。
- 培育只加速首次成長、結果進度與休養；倍率為 1＋既有成長倍率，出生附近約 1.3 倍、成體最多兩倍，各階段不短於自然時間一半，相鄰果實成熟至少隔一秒。不加速成熟後老化，不延長來源壽命。
- 沒有有效來源、全部成熟只等腐爛期限時不培育；可加速的空株仍可能有收益。新目標先選較近的可見有益來源，開始後不為稍近的新株切換，急事、失效或無收益等仍會中斷。
- 同來源只取最強效果。依可見資訊避免重複投入，強者可接手；同強度先開始者續留，完全同時公平抽選一位。容許觀察延遲造成短暫重複，不設整株獨占或遠端預約。

## 感知、呈現與回放

- 個體只觀察可見的來源粗略階段、現有果數、粗略新鮮度、持果數及互動；不讀隱藏果數、精確成熟／腐爛／休養／壽命倒數或他人未來意圖。
- 來源記憶最多 32 筆，三十秒作陳舊尺度而非直接刪除；舊資料只引導回訪，不能認定已長果。地上果實記憶最多 16 筆、離視野十秒失去追尋依據；他人持果及食物互動離視野五秒後未知，未知不等於零顆。重新看到更新，回訪落空清除。
- 親子關係與失聯搜尋沿既有規則，不因持果情報過時就忘記子女，也不新增幼體視野外追蹤親代能力。
- 四階段以植株姿態及色調辨識，果實逐顆呈現，新鮮度兼用色調與表面差異。平常不掛滿說明，選取才顯示簡短階段、果數等資訊；生長圓按選取或診斷顯示。
- 回放診斷區分世界真值、個體最後觀察與推測，還原當時行動原因。保留 v9–v14 舊回放原貌，缺少的新資訊標示未提供，不補造果實或交付。

## 驗收與延後事項

- 固定情境核對完整生命週期、食物流轉與守恆、操作中斷／同時事件／競爭／容量、負重、播種、培育、記憶與情報限制；機制錯誤本輪修正。新回放前後跳轉核對歷史快照，並比較可見與無畫面模擬結果。
- 混合物種與全苔靈各跑種子 101、102、103，共六場；每場 1200 秒模擬時間或至全滅，均從三十個剛成年個體開始，混合組每種十隻。使用正式大小世界及十二小四大來源，對齊起始位置與資源，技能沿既有抽選，保留繁殖、老化、死亡與補生。此為驗收配置。
- 保存各場結果，觀察人口、出生死亡、飽食不足、果實流量、施法原因與硬上限阻擋；全滅不剔除。並核對空間、產量與最大加速的保守供給界限；有限試跑不宣稱證明所有種子永遠穩定。
- 目前初值的保守長期產出上界約 42.44 飽食／秒，低於一百二十個體的基本需求 60／秒；這是帶假設的上界核算，不是即時人口上限、穩態保證或已完成驗收，推導見訪談 Q72–Q75。
- **本輪先試小型 2–4、大型 5–7 顆；下一輪優先看果數是否偏少，太少下一輪改。** 不把提高果數當作本輪驗收自動處置。
- 幼體照顧的長期生態對照、通用產物記錄與保留規則、PPO／混合控制實驗維持延後；不新增土壤肥力或保證全員存活的機制。後續狀態見 [future-ideas](../future-ideas.md)。
