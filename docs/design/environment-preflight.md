## 儲存安排

建議將大部分新增資料放在 D 槽，而非以 C 槽剩餘空間承擔整個開發環境：

- Editor 安裝：`D:/Tools/Unity/Editors/`。
- Editor 下載檔：`D:/Tools/Unity/Downloads/`。
- 專案、Python 虛擬環境與訓練輸出：置於目前 D 槽工作目錄。
- 套件快取與安裝暫存：安裝時以工具或單一程序設定導向 D 槽，避免修改全系統暫存設定。
- 第一版只安裝需要的桌面建置支援；回放只記錄指定場次，訓練輸出需有容量管理。

以 D 槽先預留 50–100 GiB 作為安裝、快取、建置與初期實驗的工作預算；這是規劃餘裕，不是官方最低需求或實際安裝大小。C 槽仍可能產生日誌、使用者設定及系統暫存，需保留可用空間。

[Unity Hub 官方設定文件](https://docs.unity.com/en-us/hub/settings)確認可分別設定安裝位置與下載位置；下載位置預設使用暫存目錄。變更安裝位置不會搬移既有 Editor。
