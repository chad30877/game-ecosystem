## 儲存安排

後續使用者確認 C 槽為 SSD、D 槽為 HDD，並回報 C 槽已清出約 98.7 GB。此數值是使用者回報，取代容量規劃依據，但不改寫前述歷史實測；安裝前須重新量測。

目前採用的配置取代先前「大部分新增資料放 D 槽」建議：

- C 槽 SSD：Unity Editor、開發中的專案與快取、Python 訓練環境及活躍訓練資料。
- D 槽 HDD：安裝下載檔、歷史模型、回放與備份。
- 專案目前仍在 D 槽，未搬移；開始遊戲實作前決定 SSD 上的工作位置，避免同時維護兩份來源不明的活躍專案。
- C 槽以保留 25–30 GB 可用空間作為系統與安裝暫存的規劃餘裕，不視為官方最低需求。
- 第一版只安裝需要的桌面建置支援；回放只記錄指定場次，訓練輸出需有容量管理。

實際占用依所選 Editor、模組與訓練套件確認；目前的配置決定不代表已安裝、搬移專案或更改系統設定。

[Unity Hub 官方設定文件](https://docs.unity.com/en-us/hub/settings)確認可分別設定安裝位置與下載位置；下載位置預設使用暫存目錄。變更安裝位置不會搬移既有 Editor。
