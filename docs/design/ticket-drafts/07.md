# 07：苔靈培育與護盾生存

**狀態：** draft（待確認拆分，尚未發佈）

**交付行為：** 觀看苔靈在食物附近培育並以護盾抵抗攻擊，展示第三種生存方式。

**前置任務：** 05：炎角獸近戰與烈焰衝鋒。

## 驗收條件

- [ ] 苔靈沒有傷害技能，控制器可選擇培育或護盾；技能有可見狀態、能量消耗及冷卻。
- [ ] 培育加速食物再生但不突破容量，不能無成本無限增生；苔靈滅絕後食物仍會自然再生。
- [ ] 護盾效果可從所受傷害及事件核對，炎角獸可作為驗證攻擊來源，不依賴遠程技能完成。
- [ ] 在世界循環中演示苔靈採食、使用技能及生存／死亡，確認不繞過生命與資源規則。

## 驗證方式

沿用規格提出的世界執行入口，核對可觀察結果並提供人工操作步驟；保留及執行屆時存在的有效測試。本任務不授權新增測試檔，若需要新增須先取得使用者同意。
