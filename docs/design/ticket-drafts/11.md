# 11：指定場次記錄與互動回放

**狀態：** draft（待確認拆分，尚未發佈）

**交付行為：** 記錄一場完整三物種互動，之後以時間拖動、暫停、調速及個體檢視分析歷史。

**前置任務：** 08：三物種戰術學習與連續訓練；10：即時觀察與個體檢視。

## 驗收條件

- [ ] 可指定評估場次記錄狀態及出生、死亡、技能等事件；固定評估模型時不更新策略。
- [ ] 回放由記錄還原，不重新執行模型推測原場次；可向前及向後拖動時間。
- [ ] 回放時個體狀態、存在區間與事件對應原場次；暫停與拖動不改變模型或原始資料。
- [ ] 只記錄指定場次並顯示／記錄檔案容量；支援 HDD 歷史資料配置，缺漏或不相容記錄有明確錯誤。

## 驗證方式

沿用規格提出的世界執行入口，核對可觀察結果並提供人工操作步驟；保留及執行屆時存在的有效測試。本任務不授權新增測試檔，若需要新增須先取得使用者同意。
