# 01：工具鏈與最小訓練往返

**前置任務：** 無，可立即開始。

## 驗收條件

- [ ] 核對 SSD 空間與工具相容版本，採用 SSD 活躍環境、HDD 下載及歷史資料配置；記錄實際安裝與執行位置。
- [ ] 最小個體可在畫面依控制器動作移動，Python 可完成一次實際訓練更新；不得只以套件可匯入當作成功。
- [ ] 同一場景可無畫面執行並輸出狀態、事件及步數；記錄版本、啟動方法、CPU／GPU 實際使用情況與初步吞吐量。
- [ ] 建立可供後續沿用的世界執行入口；不加入完整生態、回放或美術。遇登入／授權限制明確回報，不宣稱驗證通過。

## 驗證方式

沿用規格提出的世界執行入口，核對可觀察結果並提供人工操作步驟；保留及執行屆時存在的有效測試。本任務不授權新增測試檔，若需要新增須先取得使用者同意。
