# 12：學習成效對照與第一版驗收

**狀態：** draft（待確認拆分，尚未發佈）

**交付行為：** 使用者取得可重複執行的對照報告與回放，判斷三物種是否學到有效生存策略。

**前置任務：** 09：重建、全新實驗與關閉後續訓；11：指定場次記錄與互動回放。

## 驗收條件

- [ ] 固定初始策略、固定規則基準與訓練後策略在相同配置及 10 組固定起始種子比較，評估時停用策略更新。
- [ ] 固定其他條件逐物種檢查，再補充三物種共同演化觀察；報告保存模型版本、種子、規則及參數。
- [ ] 報告包含各物種平均壽命、繁殖、族群曲線、滅絕頻率、上限觸發、未完成生命週期樣本及變異；不把單次優勢當作可靠改善。
- [ ] 以實測吞吐量、記憶體與磁碟使用估算訓練預算；串行人工驗收觀察、技能、重建、續訓與回放。
- [ ] 若無可靠改善，標記學習效果未驗證並記錄原因與下一個具體實驗；不得以原型能啟動代替學習成效驗收。

## 驗證方式

沿用規格提出的世界執行入口，核對可觀察結果並提供人工操作步驟；保留及執行屆時存在的有效測試。本任務不授權新增測試檔，若需要新增須先取得使用者同意。
