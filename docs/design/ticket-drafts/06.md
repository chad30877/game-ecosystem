# 06：霜羽獸遠程牽制與近戰對抗

**狀態：** draft（待確認拆分，尚未發佈）

**交付行為：** 觀看霜羽獸冰箭攻擊炎角獸，重現遠程拉扯與近戰接敵窗口。

**前置任務：** 05：炎角獸近戰與烈焰衝鋒。

## 驗收條件

- [ ] 冰箭有可見停步前搖、命中效果及冷卻，狀態與事件可核對。
- [ ] 減速持續時間短於攻擊冷卻且不疊加；炎角獸衝鋒免減速仍成立。
- [ ] 演示遠程有逃離機會、近戰有接敵機會；不以單次勝負證明平衡，也不保證模型已學會操作。
- [ ] 記錄傷害、速度、減速、耗能及冷卻參數，畫面與無畫面套用同一規則。

## 驗證方式

沿用規格提出的世界執行入口，核對可觀察結果並提供人工操作步驟；保留及執行屆時存在的有效測試。本任務不授權新增測試檔，若需要新增須先取得使用者同意。
