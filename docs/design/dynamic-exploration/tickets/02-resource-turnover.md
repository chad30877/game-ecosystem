# 02：自然資源更替與播種來源壽命

**What to build:** 使用者可看到自然食物到期消失、其他合法位置逐步長出新來源，以及播種來源到期消失但不獲得自動補回。

**Blocked by:** 01：可觀察的食物枯竭與恢復。

**Status:** needs-info

草稿：僅待使用者核對驗證入口及任務拆分，尚未正式發佈或授權開始實作。

- [ ] 來源類型在存續期間穩定，壽命不因休養或培育重置；到期移除優先於同一步採食，失效技能目標安全解除。
- [ ] 自然補充只按自然來源缺額及有界節奏進行，不讀生物位置；無合法位置時延後，沒有無限重試。
- [ ] 自然與播種來源可區分，整體數量有硬上限；自然短期匱乏允許存在，播種不增加自然補充權利。
- [ ] 新增來源逐步生長，位置在合法範圍且滿足間距；初值及供給配置有記錄，策略觀察容量可容納動態數量。
- [ ] 固定種子重現新增與消失序列，可見／無畫面一致；事件、畫面與橋接皆反映變化。
- [ ] 核對來源消失時採食／培育、滿額播種及空間不足情境，保留既有技能成本與拒絕行為。
