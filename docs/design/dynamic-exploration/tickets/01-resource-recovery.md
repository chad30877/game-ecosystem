# 01：可觀察的食物枯竭與恢復

**What to build:** 使用者可在既有世界入口觀看不同生長類型的食物被吃光、休養、恢復至門檻，再重新採食；規則展示與學習橋接收到相同的可採食狀態。

**Blocked by:** 無；可於正式發佈後開始。

**Status:** needs-info

草稿：僅待使用者核對驗證入口及任務拆分，尚未正式發佈或授權開始實作。

- [ ] 配置可指定生長類型、容量、生長速度、休養時間與恢復門檻；驗證非法值，完整參數寫入執行紀錄。
- [ ] 可採食、休養及恢復生長各階段符合規格；門檻前無法採食，存量維持合法範圍。
- [ ] 培育不解除休養，恢復生長時可促進生長；播種原有成熟等待與技能成本仍有效。
- [ ] 可見及無畫面固定場景可重現一個完整枯竭／恢復循環；畫面以簡潔狀態呈現差異，策略可辨識可採食狀態。
- [ ] 必要的世界與觀察版本隨介面變更更新，拒絕不相容舊模型；既有新版本 bridge 可往返。
- [ ] 記錄人工操作與對外事件證據，通過建置及相關技能、覓食回歸；不新增測試檔。
