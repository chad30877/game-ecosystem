# 資源動態化與主動探索發佈草稿

[規格草稿](spec-draft.md)依已定案訪談合成。待使用者核對驗證入口及下列切片後，移至本機追蹤器 `.scratch/dynamic-resources-and-exploration/`；規格使用 `spec.md`，各任務使用 `issues/` 並標記 ready-for-agent。此處尚非可執行任務。

主要驗證入口沿用世界執行入口，透過固定配置、種子與指定動作核對對外狀態及事件，再串接訓練、保存、觀察與回放。不新增測試檔或額外私有測試入口。

| 編號 | 任務 | 前置任務 | 可獨立驗證的結果 |
| --- | --- | --- | --- |
| 01 | [可觀察的食物枯竭與恢復](tickets/01-resource-recovery.md) | 無 | 食物被吃光後休養，達恢復門檻才可採食，培育不能跳過休養。 |
| 02 | [自然資源更替與播種來源壽命](tickets/02-resource-turnover.md) | 01 | 自然來源消失及換位置生長，播種來源到期但不自動補回。 |
| 03 | [方向食物視野與個體探索記憶](tickets/03-perception-memory.md) | 01 | 轉身發現食物，記憶過時、撲空及重觀察後修正。 |
| 04 | [合理定居時的基本掃視保障](tickets/04-basic-scanning.md) | 03 | 定居仍補看周圍，緊急時可暫緩，分辨主動與系統介入。 |
| 05 | [可保存續訓的探索學習循環](tickets/05-learned-exploration.md) | 02、04 | 完整環境中的探索學習、有限獎勵及保存續訓往返。 |
| 06 | [資源、記憶與掃視的歷史觀察](tickets/06-observation-replay.md) | 05 | 錄製並回放新狀態，區分世界真值與個體當時所知。 |
| 07 | [探索與生存行為的多種子驗收](tickets/07-behavior-evaluation.md) | 06 | 用場景、對照報告與回放判斷生存及覓食是否改善。 |

## 依賴理由

- 01 完成後，02 與 03 可分別進行；03 以指定動作改變食物狀態，不需要等待自然更替。
- 04 需要 03 的方向觀察與資訊新鮮度；05 需要完整動態環境與掃視保障，避免以不同規則完成訓練。
- 06 要記錄並重現 05 的探索獎勵及完整新觀察；07 使用 06 的歷史證據，亦間接依賴前述所有切片。
- 沒有單列預先重構任務；必要的局部調整併入各可驗證切片。任務依賴不代表授權啟動平行 agent。
