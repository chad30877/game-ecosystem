# 資源動態化與主動探索規格草稿

行為範圍已定案；本草稿待核對驗證入口與任務拆分後，移至本機追蹤器並標記 ready-for-agent。參數為可調初值，不代表已驗證平衡。

## Problem Statement

目前食物持續在固定位置再生，單一生物可能長期停留便能維生。食物採全方向範圍感知，原地轉向不會增加食物資訊；生物缺少環境探索記憶，也沒有定居時更新身後資訊的基本保障。單純增加移動或轉向獎勵會產生繞圈、空轉與冒險刷分，無法代表更好的生存能力。

文件數量本身不是問題；現有導航已能按需找到正式規格與歷史紀錄，因此不進行大規模文件整理。後續構想已有集中清單並接入設計訪談。

## Solution

讓食物來源具有枯竭、休養、恢復及有限生命週期，形成隨時間改變的供給。生物依自己的方向視野與有限探索記憶，在覓食、停留、撤退及探索間選擇；安全且供給足夠時仍可合理定居。原地掃視提供最低限度的資訊更新，緊急求生優先。訓練只對首次觀察新區域提供有上限的輔助獎勵，主要效果以生存、覓食及實際反應評估。

## User Stories

1. 作為觀察者，我希望看到食物被採集至枯竭，以理解供給有限。
2. 作為觀察者，我希望枯竭來源經過休養才恢復，以避免立即再生被守候者吃掉。
3. 作為觀察者，我希望恢復到一定存量才開放採食，以看見有效的補給窗口。
4. 作為觀察者，我希望不同來源有穩定的生長類型，以辨識值得重訪的地方。
5. 作為觀察者，我希望自然來源會消失及在其他位置生長，以看到分布變化。
6. 作為實驗操作者，我希望資源更替獨立於生物位置，以避免世界刻意餵養個體。
7. 作為實驗操作者，我希望供給有整體限制且容許短期匱乏，以觀察真實的生存壓力。
8. 作為觀察者，我希望播種來源同樣會枯竭與消失，以避免永久補給漏洞。
9. 作為觀察者，我希望培育仍能改善生長，但不能解除休養，以保留物種特色與限制。
10. 作為觀察者，我希望食物必須進入方向視野才被發現，以讓轉向有資訊價值。
11. 作為觀察者，我希望生物保留最後觀察的食物情報，以支援離開視野後的覓食。
12. 作為觀察者，我希望視野外的記憶不自動更新，以允許舊情報失效。
13. 作為觀察者，我希望生物撲空後修正記憶與選擇，以避免永久前往已消失的來源。
14. 作為觀察者，我希望曾探索區域的資訊會過時，以使重訪具有意義。
15. 作為實驗操作者，我希望記憶容量有限，以維持可控成本。
16. 作為觀察者，我希望各個體自行累積記憶，以避免同物種共享全世界情報。
17. 作為觀察者，我希望後代自行觀察環境，以避免繼承親代地圖。
18. 作為實驗操作者，我希望重建世界清除環境記憶而可保留策略，以區分兩種經驗。
19. 作為觀察者，我希望供給充足時允許定居，以免生物被迫無益移動。
20. 作為觀察者，我希望定居生物仍掃視周圍，以察覺身後新威脅。
21. 作為觀察者，我希望緊急求生能暫緩掃視，以避免逃命時被強迫回頭。
22. 作為觀察者，我希望模型已主動觀察時不被多餘介入，以保留策略選擇。
23. 作為實驗操作者，我希望區分主動轉向與補上的掃視，以正確解讀學習成果。
24. 作為實驗操作者，我希望只對首次觀察的新區域給有限獎勵，以鼓勵取得資訊。
25. 作為實驗操作者，我希望遺忘、等待及繞圈不能重置獎勵，以避免刷分。
26. 作為觀察者，我希望飢餓或危險時生物優先求生，以免為探索送命。
27. 作為實驗操作者，我希望訓練及觀察使用同樣的世界與掃視規則，以避免部署時行為改變。
28. 作為實驗操作者，我希望新介面拒絕不相容舊模型，以避免誤用觀察語意。
29. 作為觀察者，我希望回放能重現資源狀態、記憶與掃視，以檢查行為原因。
30. 作為實驗操作者，我希望固定場景及多組種子提供可比較結果，以判斷是否改善生存。
31. 作為實驗操作者，我希望報告包含實測成本與未完成項目，以避免把技術往返當成學習成功。
32. 作為規劃者，我希望後續構想維持獨立清單，以在未來訪談中再決定是否實作。

## Implementation Decisions

### 資源生命週期

- 沿用 World 的固定步長與食物來源，來源包含生長類型、存量、容量、休養進度、可採食狀態、出生時間及自然／播種來源區別。來源識別僅供世界內部與紀錄，不新增策略可用的追蹤識別碼。
- 狀態順序為可採食、枯竭休養、恢復生長、達門檻後可採食；休養時不生長、不採食。恢復生長時培育可加速生長，但達門檻前仍不可採食。可採食狀態持續生長，直到枯竭再次休養。
- 原有播種成熟等待仍保留，不能因本次變更立即開放新播種。有限壽命按來源建立起的世界時間計算，不因休養、培育或再次枯竭重置；到期移除優先於該步採食，清除失效培育目標。
- 提議初始生長類型：小型容量 15、每秒生長 0.75、休養 10 秒、壽命 120 秒；大型容量 30、每秒生長 1.5、休養 25 秒、壽命 240 秒；恢復門檻均為容量 25%。數值皆需驗證與可配置，名稱與存量呈現不增加冗長說明。
- 自然來源總量以配置上限控制；沿用起始規模作初值，按可調間隔補充缺額，每次新增數有上限。位置以有種子的亂數在世界合法範圍、來源最小間距條件下選取，不讀取生物位置；找不到位置則延後，不無限重試。新來源由低存量逐步生長，不瞬間補滿。
- 自然補充只計自然來源缺額；播種受既有成本、合法位置與來源容量限制，死亡不產生自動補回權利。保留整體來源硬上限，避免記錄及感知容量無限膨脹。

### 方向視野與探索記憶

- 食物沿用生物的 120° 方向視野及觀察半徑，不新增遮擋系統。當前可見資訊與記憶資料明確區分，視野外不可用世界真值刷新存量、成熟或存在狀態。
- 個體記錄曾觀察區域、最後觀察時間、食物最後位置與狀態，以及既有近期威脅資訊。只有區域實際進入視野時才更新；重新觀察未發現舊來源時撤銷該筆可用食物情報。
- 提議以 2 × 2 世界單位格網表示區域，以格心進入視野作一致的觀察判定；近期區域記憶上限 64、食物記憶上限 32、食物情報 30 秒標為過時，既有威脅記憶時間先維持。皆為可調初值；過時不代表來源必然消失。
- 記憶淘汰優先保留近期威脅及近期有用食物資訊；不改動既有當前可見生物不截斷的規則。策略取得有限、正規化且區分新舊的觀察，不取得全圖實時狀態。
- 首次觀察資格使用獨立、由有限世界格網界定大小的集合；它只用於獎勵資格，不作無限詳細環境記憶提供給策略。遺忘不能恢復領獎資格。
- 死亡移除記憶，新生與世界重建重新累積；物種策略共享不共享個體環境記憶。

### 掃視與探索行為

- 沿用獨立轉向動作，不增加頭部控制。記錄各方向資訊新鮮度，非緊急且長時間未觀察周圍時優先補看較舊方向；每步遵守既有轉速上限，已主動更新則不介入。
- 掃視新鮮度初值為 8 秒；不可將一次轉滿 360° 視為唯一完成條件。採食可持續但不能永久阻止觀察；已知近迫威脅、正在緊急逃離或能量危急可暫緩，理由與延後時間可觀察。危機解除後恢復補看；緊急判定只使用個體合法資訊，不能因視野外真實敵人啟動。
- 世界記錄原始轉向、實際轉向、介入原因及是否延後；基本掃視在規則展示、訓練與固定模型觀察中使用相同規則。指定動作驗證可明確控制掃視開關，對照各條件需記錄一致設定。
- 規則展示以既有局部覓食結合記憶與未知／過時區域選擇，避免固定巡邏；學習策略自行選擇移動、停留及撤退，不由展示控制器接管移動。
- 沿用存活、繁殖與死亡獎勵；首次觀察區域的輔助獎勵提議每格 0.0001、每個體生命總上限 0.02。初始視野可計入但仍受上限限制；不對距離、轉向、重訪或情報過時額外發分。獎勵分項記錄，不能把發分本身當成探索成功。

### 訓練、保存與觀察契約

- World、ForagingController、WorldAgent 與 Python 訓練／觀察介面需共同支援新資源狀態及個體記憶；版本變更涵蓋規則、觀察語意、記錄與完整配置。
- 舊模型與新觀察不相容時明確拒絕載入並要求全新實驗；保留既有檔案，不自動遷移。新版本保存、續訓、重建與全新實驗維持原本的策略生命週期；續訓建立新世界時不恢復上一世界的個體記憶。
- 動態來源的新增／消失與記憶需在即時觀察、記錄及回放保持一致。全景可顯示真值，個體檢視區分可見與舊情報；全景資料不回流至策略。新增資料以狀態與簡短標記呈現。
- 沒有證據需要先做廣泛重構；各切片僅作必要的局部調整，共用狀態規則避免展示、訓練與回放各自實作不同生命週期。

## Testing Decisions

- 待核對的主要驗證入口：沿用世界執行入口，固定配置、種子及指定動作，檢查 World.Step／Observe 對外狀態、事件與個體觀察；訓練、觀察及回放由同入口串接。避免另設私有函式測試入口。
- 先例是既有覓食、生命循環、技能視野固定場景、bridge 往返、保存續訓及多種子評估。保留並執行仍適用的既有驗證；現階段不新增測試檔。如發現具體回歸風險且現有驗證無法涵蓋，再另行提出新增測試檔需求。
- 資源檢查：門檻前不可採食、休養不被培育解除、恢復後可消耗、無負存量或超容量、來源到期移除、新增位置合法、無合法位置不阻塞、相同種子及動作可重現。
- 感知檢查：背後食物不可見、轉向後可見、離開視野的存量與存在狀態保持舊值、再觀察後修正、容量有界、死亡及重建清除、後代不繼承。
- 獎勵檢查：往返、原地轉圈、記憶淘汰及等待過時均不能重複領取；同區域首次更新也不得一世界步重複結算，累計不超上限。
- 掃視檢查：安全定居能重新觀察各方向、可發現持續存在的身後新威脅；緊急狀態可延後、解除後恢復；模型已更新時不多餘介入。記錄主動與保障行為，不能承諾捕捉所有瞬間經過的敵人。
- 學習行為場景：食物枯竭後找替代、依舊記憶撲空後調整、能量低時選擇已知食物、充足供給時允許停留且有掃視。規則展示通過不等於模型通過。
- 使用相同新世界配置與種子比較初始策略、規則及訓練策略，必要時比較關閉資訊獎勵的訓練對照；基本掃視設定保持一致。至少十組評估種子，報告逐物種生存、飢餓、採食、探索覆蓋、重複路徑及主動／介入掃視。
- 短場景用於機制驗證；學習評估時長須足以跨越資源更替及記憶過時，不能沿用短至事件尚未發生的設定宣稱完成。先以小規模實測訓練成本，保存精確初始權重、獨立訓練種子與預算，延用既有多次獨立訓練原則；執行前固定比較指標與門檻，不能看結果後挑選成功種子。
- 量化結果至少呈現平均、種子間變異與未完成生命樣本；若生存／覓食未改善或有未通過情境，保持學習效果未驗證及任務未完成，記錄限制與下一次調整。沒有固定要求每隻個體都探索或都存活。
- Unity 建置、Python 與 PowerShell 既有檢查、bridge、技能與生命循環回歸仍執行；可見／無畫面狀態一致、模型相容性拒絕及回放前後拖動均需核對。

## Out of Scope

- 飲水及獨立飢餓系統；本期仍以食物與能量表達生存壓力。
- 幼體戰力、親代保護、獨立頭部控制、季節、土壤、氣候與遮擋。
- 強迫離開安全定居地、固定巡邏路線、對單純距離或重訪發分。
- 共享全圖情報、後代繼承個體地圖、在視野外刷新記憶。
- 大規模文件刪整、通用架構重構及未經同意新增測試檔。
