# 幼體與成體能力差異訪談

## 已確認

- 幼體比成體弱，仍能自行覓食、逃跑及使用自身能力；能力隨年齡逐漸提升。
- 成長只依時間推進；缺糧不直接暫停成長，飢餓仍依既有規則影響生存。
- 健康上限、普通攻擊威力及技能數值隨成長提升；移動、覓食與感知維持完整能力。各項比例與技能數值的具體範圍尚待討論。
- 本次不納入親代保護；未來要設計親代保護，也可能加入給予食物的功能，具體規則尚未決定。

## 現有基礎

- 預設成長期為 30 模擬秒，期間不能繁殖；新生個體健康、體力與魔力滿值，飽食度為 30。
- 同物種幼體與成體目前的能力未依年齡縮放；後代出生時獨立取得固定技能配置。
