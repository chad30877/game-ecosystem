# 第一版小型生態世界

狀態：需求訪談中，尚未確認完整設計。

## 已確認方向

- 世界包含三個物種，各自具有特色與魔法技能。
- 初期以觀察世界為主，後續希望加入玩家參與。
- 資源直接影響生存與繁殖。
- 至少兩個物種偏向戰鬥。
- 資源競爭引發戰鬥；生物受傷或處於劣勢時會撤退。
- 第三個物種偏向培育與防禦，以魔法促進資源生長並保護自己。
- 允許物種完全滅絕，觀察者可重新開始世界。
- 未來玩家操控一隻生物，參與覓食、戰鬥與施法；第一版仍以觀察為主。
- 三個物種共用一種會自然再生的食物；培育者加速其生長，並非唯一來源。第一版不加入捕食或食用屍體。
- 進食補充能量，日常活動與施法消耗能量；魔法另有冷卻時間。
- 營養充足的個體可自行繁殖同物種後代，消耗親代能量並受到繁殖冷卻限制。後代經過成長期才可繁殖；第一版不加入性別、遺傳與突變。
- 生物可因飢餓、戰鬥或壽命耗盡而死亡。

## 尚未採納的物種提案

曾提出耐打但緩慢的近戰炎角獸、快速且能以冰箭減速的遠程霜羽獸，以及培育兼防禦的苔靈。使用者指出炎角獸可能持續被拉扯，因此此組配置尚未確認；需先確定近戰接敵、遠程攻擊限制與停止追擊的規則。

## 待釐清

- 兩個戰鬥物種的具體差異與魔法技能。
- 戰鬥收益、追擊與撤退規則。
- 資源、繁殖、魔法與個體行為的具體規則。
- 世界呈現、觀察操作與第一版完成條件。
