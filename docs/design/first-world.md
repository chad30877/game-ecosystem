# 第一版小型生態世界

狀態：需求訪談中，尚未確認完整設計。

## 已確認方向

- 世界包含三個物種，各自具有特色與魔法技能。
- 初期以觀察世界為主，後續希望加入玩家參與。
- 資源直接影響生存與繁殖。
- 至少兩個物種偏向戰鬥。
- 資源競爭引發戰鬥；生物受傷或處於劣勢時會撤退。
- 第三個物種偏向培育與防禦，以魔法促進資源生長並保護自己。
- 允許物種完全滅絕，觀察者可重新開始世界。
- 未來玩家操控一隻生物，參與覓食、戰鬥與施法；第一版仍以觀察為主。

## 待釐清

- 兩個戰鬥物種的具體差異與魔法技能。
- 資源來源、戰鬥收益與施法代價。
- 資源、繁殖、魔法與個體行為的具體規則。
- 世界呈現、觀察操作與第一版完成條件。
