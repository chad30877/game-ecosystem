# 第一版小型生態世界

狀態：訪談共識已整理，初始實作預設待整體核對；尚未開始遊戲實作或技術驗證。

## 已確認方向

- 世界包含三個物種，各自具有特色與魔法技能。
- 初期以觀察世界為主，後續希望加入玩家參與。
- 資源直接影響生存與繁殖。
- 至少兩個物種偏向戰鬥。
- 資源競爭引發戰鬥；期望生物學會在受傷或處於劣勢時撤退，不以強制行為規則保證。
- 第三個物種偏向培育與防禦，以魔法促進資源生長並保護自己。
- 允許物種完全滅絕，觀察者可重新開始世界。
- 未來玩家操控一隻生物，參與覓食、戰鬥與施法；第一版仍以觀察為主。
- 三個物種共用一種會自然再生的食物；培育者加速其生長，並非唯一來源。第一版不加入捕食或食用屍體。
- 進食補充能量，日常活動與施法消耗能量；魔法另有冷卻時間。
- 營養充足的個體可自行繁殖同物種後代，消耗親代能量並受到繁殖冷卻限制。後代經過成長期才可繁殖；第一版不加入性別、遺傳與突變。
- 生物可因飢餓、戰鬥或壽命耗盡而死亡。

## 戰鬥與資源分布

- 炎角獸平常移動較慢，以短距離烈焰衝鋒取代原提案的噴火；衝鋒消耗能量、有冷卻，期間不受減速影響。
- 霜羽獸施放冰箭前必須短暫停下，具有可見前搖；減速持續時間短於攻擊冷卻，重複命中不疊加減速。
- 爭奪資源以取得或保住食物為目的；對手離開後停止追擊並返回進食，是期望學到的策略，不是強制規則。
- 食物主要集中在數處產地，外圍保留少量零散食物供落敗者恢復。
- 上述接敵與施法限制用來處理慢速近戰可能遭快速遠程持續拉扯的問題；具體數值尚待確定。

## 學習需求

- 同物種共享學到的策略，個體仍可做出不同選擇；經驗不因單一個體死亡而全部消失。
- 學習內容包括何時採食、交戰、施法、撤退，以及去哪裡尋找食物。技能本身與身體能力保持固定。
- 允許個體追擊過遠、浪費能量等錯誤，再依結果改變選擇；技能冷卻與能量消耗等世界規則固定。
- 從基本能活動、尚不擅長生存的狀態開始，在觀察期間持續學習。
- 重建世界時可保留已學到的物種策略，透過多個世界累積經驗；另提供全新實驗，同時清除世界與策略。此決策取代原先每次重建都清除經驗的限制。
- 食物未來希望擴充為另有設計的系統，目前維持已確認的簡單規則，後續系統細節尚未定義。
- 學習以維持生存與成功繁殖為主要目標，不直接獎勵傷害或擊殺，也不保證物種共存。
- 個體只感知附近食物與生物，以及自身健康、能量與技能狀態；共享策略不等於共享全地圖即時情報。
- 以相同起始條件下、多次開啟與關閉學習的模擬作對照，觀察平均壽命、繁殖數與族群變化。

## 訓練與呈現方向

- 提供本機執行的 2D 俯視世界，每個物種初始約 10 隻；以簡單可辨識的外形與技能效果呈現。
- 觀察操作包含暫停、調速、鏡頭縮放與點選個體，顯示健康、能量、年齡與技能冷卻。
- 採戰術操作層級：模型決定移動方向、瞄準與攻擊及技能時機；世界執行基本移動、碰撞與技能效果，不學習關節控制。
- 以 Unity＋ML-Agents＋Python 作為技術驗證方向；先驗證三物種各自共享策略、個體出生死亡與無畫面訓練，再正式定案。
- 技術方向參考 [Unity ML-Agents 概覽](https://github.com/Unity-Technologies/ml-agents/blob/develop/com.unity.ml-agents/Documentation~/ML-Agents-Overview.md)與[訓練文件](https://unity-technologies.github.io/ml-agents/Training-ML-Agents/)。
- 每輪於模擬時間上限或全部生物死亡時結束；單一物種滅絕不提前結束。訓練模式自動保留策略並重建三物種世界。
- 訓練支援無畫面執行，保留統計，定期記錄指定評估場次的世界狀態與事件。
- 回放提供暫停、調速、時間拖動與個體檢視；回放不更新策略，也不接受玩家介入改寫。
- 保存三物種策略及接續訓練所需的狀態，關閉後可從新世界續訓；第一版不提供原世界精確存檔後繼續。
- 血量、速度、冷卻、壽命、再生率、獎勵權重與人口上限由實作者提出可調初值，再依模擬結果修正。規則與參數變更需記錄。

## 初始實作預設提案

以下為實作者提出的起始配置，供整體設計核對；不是已驗證的平衡結果。

- 使用炎角獸、霜羽獸、苔靈作為第一版名稱。苔靈主動選擇培育或護盾，沒有傷害技能；另外兩種可攻擊異種，不傷害同種，第一版不加入外交與同種內鬥。
- 單張有邊界、無障礙物的平面地圖，先驗證生態與戰術；不加入高低差、季節或地形破壞。
- 食物不可攜帶，個體接近食物並選擇採食才取得能量。食物自然再生受產地容量限制，培育加速再生而不突破容量。
- 繁殖在成年、能量與冷卻條件滿足時自動觸發；採食、移動、攻擊及技能時機交由策略選擇。後代不繼承親代身體數值變化。
- 健康與能量分開；能量耗盡後持續損失健康，健康歸零或壽命耗盡死亡。能量充足且脫離戰鬥時緩慢恢復健康。
- 人口上限限制新增出生，不移除既有個體；記錄上限觸發次數，避免將受上限抑制的繁殖誤判為學習失敗。

| 參數 | 初始值 |
| --- | --- |
| 地圖大小 | 40 × 40 世界單位 |
| 初始數量 | 每物種 10 隻，初始個體為成年 |
| 人口上限 | 全世界 120 隻 |
| 食物分布 | 4 處產地，外圍少量零散食物 |
| 每輪長度 | 600 模擬秒 |
| 成長期／壽命 | 30／240 模擬秒 |
| 能量上限／初始能量 | 100／60 |
| 繁殖條件／消耗／冷卻 | 能量至少 80／40／30 模擬秒 |
| 炎角獸／霜羽獸／苔靈健康 | 120／70／90 |
| 炎角獸／霜羽獸／苔靈移速 | 每模擬秒 2.5／3.2／2.7 世界單位 |

攻擊傷害、施法與再生消耗等數值在最小戰鬥場景中一起校準；需驗證近戰可接敵、遠程有撤離機會、培育不可無成本無限增生。這些數值都屬已授權的調參範圍。

## 實作與驗證順序提案

1. **技術驗證**：確認本機工具版本與相容性，建立最小場景，驗證三個獨立物種策略、同種參數共享、出生死亡、無畫面執行，以及儲存與續訓。失敗時先回報具體阻礙，再決定替代架構。
2. **世界循環**：完成移動、戰鬥、食物、生存、繁殖與死亡。規則控制器僅用於檢查世界和建立比較基準，不算已完成學習。
3. **學習與評估**：接入戰術動作與局部感知，校準獎勵及探索；記錄訓練步數、參數與模型版本。
4. **觀看與回放**：完成觀察介面、指定評估場次記錄及可拖動時間的回放，驗證狀態與事件一致。

## 第一版驗收提案

- 三個物種可完成採食、繁殖、死亡及各自技能；允許滅絕，不強制平衡。
- 可觀看互動、無畫面訓練、重建並保留策略、開啟全新實驗，以及關閉後從新世界續訓。
- 回放可重現所記錄場次的出生、死亡、技能與個體狀態；暫停及拖動時間不推進訓練。
- 評估區分「模型依已學策略行動」與「更新模型」。固定模型評估時關閉更新，不將推論誤認為學習。
- 對照包含固定初始策略、固定規則基準與訓練後策略；使用相同世界規則及成組起始種子，評估時固定其他條件，逐物種檢查並補做三物種共同演化觀察。
- 記錄各物種平均壽命、繁殖數、族群曲線、滅絕頻率及未完成生命週期的樣本；不以單次勝負或人口總量認定學習有效。
- 先以 10 組固定評估種子作初步比較，呈現變異與不確定性；若看不出可靠改善，明確標示學習效果未驗證，不把可執行原型視為學習目標已達成。
- 尚未承諾訓練耗時或效能數字；以技術驗證的實測吞吐量估算首輪實驗預算。

## 後續範圍

玩家操控單一生物、擴充食物系統、原世界存檔、遺傳突變與精緻美術均不納入第一版。Unity 技術選型待驗證通過後正式定案；完整設計待使用者確認共同理解後進入實作。
