# 第一版小型生態世界

狀態：需求訪談中，尚未確認完整設計。

## 已確認方向

- 世界包含三個物種，各自具有特色與魔法技能。
- 初期以觀察世界為主，後續希望加入玩家參與。
- 資源直接影響生存與繁殖。
- 至少兩個物種偏向戰鬥。
- 資源競爭引發戰鬥；生物受傷或處於劣勢時會撤退。
- 第三個物種偏向培育與防禦，以魔法促進資源生長並保護自己。
- 允許物種完全滅絕，觀察者可重新開始世界。
- 未來玩家操控一隻生物，參與覓食、戰鬥與施法；第一版仍以觀察為主。
- 三個物種共用一種會自然再生的食物；培育者加速其生長，並非唯一來源。第一版不加入捕食或食用屍體。
- 進食補充能量，日常活動與施法消耗能量；魔法另有冷卻時間。
- 營養充足的個體可自行繁殖同物種後代，消耗親代能量並受到繁殖冷卻限制。後代經過成長期才可繁殖；第一版不加入性別、遺傳與突變。
- 生物可因飢餓、戰鬥或壽命耗盡而死亡。

## 戰鬥與資源分布

- 炎角獸平常移動較慢，以短距離烈焰衝鋒取代原提案的噴火；衝鋒消耗能量、有冷卻，期間不受減速影響。
- 霜羽獸施放冰箭前必須短暫停下，具有可見前搖；減速持續時間短於攻擊冷卻，重複命中不疊加減速。
- 爭奪資源以取得或保住食物為目的；對手離開後停止追擊並返回進食。
- 食物主要集中在數處產地，外圍保留少量零散食物供落敗者恢復。
- 上述接敵與施法限制用來處理慢速近戰可能遭快速遠程持續拉扯的問題；具體數值尚待確定。

## 學習需求

使用者希望物種可以學習。學習主體、內容、記憶延續範圍及第一版實作方式尚未確認。

## 待釐清

- 物種的最終名稱、技能細節與戰鬥數值。
- 學習如何影響行為選擇，以及與已確認追擊、撤退規則的關係。
- 資源、繁殖、魔法與個體行為的具體規則。
- 世界呈現、觀察操作與第一版完成條件。
