# 資源動態化與主動探索訪談

本文件為設計背景，尚未形成正式規格或可執行任務。

## 已確認原則

- 允許合理定居：安全且供給足夠時，生物可以長期停留。需要避免的是固定位置無條件滿足所有生存需求。
- 允許提供基本探索動機與有限記憶；不指定固定巡邏路線，探索、停留與撤退仍依個體狀況決定。
- 生存優先於探索；返回已知食物補給可以是合理行為，不能只因往返或停留就判定失敗。
- 本期資源限於食物，沿用能量表達生存壓力，不新增獨立飢餓或飲水系統。
- 探索涵蓋從未觀察的區域及情報已過時的區域；記憶屬於個體，同物種共享策略不代表共享資源情報。重新確認過時情報不保證有收益。
- 播種來源同樣受到枯竭與恢復限制；培育保留改善供給的優勢，但不能無成本產生永久供給。
- 環境與個體記憶支援規則展示控制器及學習策略，以訓練後學習策略的生存、覓食與探索表現為主要驗收對象。
- 食物被吃光後進入無法採食的休養期，之後重新生長；不同點具有不同生長速度與休養時間，播種來源也遵守休養規則。尚未枯竭時可以持續生長。
- 自然食物來源即使無人採集，也可消失並在其他適合位置逐步出現；更替不因個體停留時間觸發，不刻意在個體身旁補給。控制整體供給範圍，允許短期匱乏。
- 探索記憶只保存個體實際觀察的資訊及其新舊程度；視野外不自動更新，依舊情報前往卻撲空是允許的結果。
- 允許取得新情報的少量訓練輔助獎勵，但限制總量與重複收益，不獎勵移動距離，也不能只靠等待情報過時或繞圈持續得分。主要成效仍以生存與覓食改善評估。
- 停留時提供基本掃視機制，不能無限期忽略身後；學習策略可調整觀察重點。戰鬥時可優先關注眼前威脅，不強迫固定間隔完整轉一圈。
- 食物與其他生物同樣受方向視野限制；離開視野後依靠記憶，不即時更新食物存量。
- 本期以既有原地轉身能力實現掃視，不新增獨立頭部朝向。

## 新增設計問題

使用者指出：即使資源足夠、允許合理定居，生物仍應考慮原地轉頭可及範圍的資訊更新與周圍警戒。資源枯竭與遠處探索本身不足以保證此行為；已確認以基本掃視及方向視野處理，仍需釐清行為協調及驗收情境，不能將原地不移動直接視為沒有探索需求。

## 待釐清

- 個體記憶的具體內容、容量與有效期限。
- 資源更替、休養及培育影響的細節。
- 資訊獎勵的觸發與防止重複獲利的方式。
- 掃視與採食、戰鬥的協調及驗收情境。
- 行為評估與驗收方式。
