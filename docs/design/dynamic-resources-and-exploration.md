# 資源動態化與主動探索訪談

本文件保留設計訪談背景；實作以[正式規格與任務](../../.scratch/archive/dynamic-resources-and-exploration/README.md)為準。

## 已確認原則

- 允許合理定居：安全且供給足夠時，生物可以長期停留。需要避免的是固定位置無條件滿足所有生存需求。
- 允許提供基本探索動機與有限記憶；不指定固定巡邏路線，探索、停留與撤退仍依個體狀況決定。
- 生存優先於探索；返回已知食物補給可以是合理行為，不能只因往返或停留就判定失敗。
- 本期資源限於食物，沿用能量表達生存壓力，不新增獨立飢餓或飲水系統。
- 探索涵蓋從未觀察的區域及情報已過時的區域；記憶屬於個體，同物種共享策略不代表共享資源情報。重新確認過時情報不保證有收益。
- 播種來源同樣受到枯竭與恢復限制；培育保留改善供給的優勢，但不能無成本產生永久供給。
- 環境與個體記憶支援規則展示控制器及學習策略，以訓練後學習策略的生存、覓食與探索表現為主要驗收對象。
- 食物被吃光後進入無法採食的休養期，之後重新生長；不同點具有不同生長速度與休養時間，播種來源也遵守休養規則。尚未枯竭時可以持續生長。
- 自然食物來源即使無人採集，也可消失並在其他適合位置逐步出現；更替不因個體停留時間觸發，不刻意在個體身旁補給。控制整體供給範圍，允許短期匱乏。
- 探索記憶只保存個體實際觀察的資訊及其新舊程度；視野外不自動更新，依舊情報前往卻撲空是允許的結果。
- 允許取得新情報的少量訓練輔助獎勵，但限制總量與重複收益，不獎勵移動距離，也不能只靠等待情報過時或繞圈持續得分。主要成效仍以生存與覓食改善評估。
- 停留時提供基本掃視機制，不能無限期忽略身後；學習策略可調整觀察重點。戰鬥時可優先關注眼前威脅，不強迫固定間隔完整轉一圈。
- 食物與其他生物同樣受方向視野限制；離開視野後依靠記憶，不即時更新食物存量。
- 本期以既有原地轉身能力實現掃視，不新增獨立頭部朝向。
- 逃命、應對眼前敵人或即將餓死等緊急求生行為可以暫緩掃視，危機解除後補看長時間未觀察的方向；採食本身不能永久阻止掃視。
- 第一版資訊輔助獎勵只給個體首次觀察的新區域，設有總量上限；情報過時或被遺忘不重置領獎資格。重訪與日常掃視不額外發分。
- 培育可促進生長，但不能直接解除休養；播種來源具有有限生命週期，消失後不自動在其他位置補回。自然資源的更替另行維持整體供給。
- 新生個體自行累積探索記憶，不繼承親代的環境情報；重建世界清除環境記憶，但仍可依既有設定保留已學策略。記憶有限，優先保留近期威脅與有用食物情報，久遠資訊逐漸失效。
- 以具體生存情境驗收：供給充足時合理定居並持續掃視、枯竭後尋找替代來源、依過時記憶撲空後調整行動，以及察覺身後新威脅。同時檢查重複繞圈與空轉得分，不要求每個個體採取相同行為。
- 休養時間、來源壽命、記憶容量與過時時間、掃視間隔及資訊獎勵上限均為可調參數；先制定有理由的初值，再以固定場景及多組種子評估調整，不將未驗證的數值定為固定要求。
- 枯竭後依序經過休養、恢復生長，達到可調的存量門檻才重新開放採食；開放後正常消耗，直到再次枯竭。
- 第一版採少量生長類型形成食物點差異，例如恢復快但容量小、恢復慢但容量大。來源建立時決定類型，存續期間保持穩定；新來源在合法位置生成，不依生物位置安排。本期不加入季節、土壤或氣候系統。
- 基本掃視作為共同的行為保障：非緊急且長時間未觀察周圍時可介入轉向。訓練與實際運行使用相同規則；模型已主動更新資訊時不介入，評估分別記錄主動轉向與系統補上的掃視，不將保障效果視為模型自行學會警戒。

## 新增設計問題

使用者指出：即使資源足夠、允許合理定居，生物仍應考慮原地轉頭可及範圍的資訊更新與周圍警戒。資源枯竭與遠處探索本身不足以保證此行為；已確認以基本掃視及方向視野處理，並納入定居及身後新威脅的驗收情境，不能將原地不移動直接視為沒有探索需求。

- 個體記憶的資料內容、容量與過時時間，以及首次觀察區域的判定尺度。

- 固定場景、多組種子與行為比較的量化門檻。
