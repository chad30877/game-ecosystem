# 資源動態化與主動探索訪談

本文件為設計背景，尚未形成正式規格或可執行任務。

## 已確認原則

- 允許合理定居：安全且供給足夠時，生物可以長期停留。需要避免的是固定位置無條件滿足所有生存需求。
- 允許提供基本探索動機與有限記憶；不指定固定巡邏路線，探索、停留與撤退仍依個體狀況決定。
- 生存優先於探索；返回已知食物補給可以是合理行為，不能只因往返或停留就判定失敗。
