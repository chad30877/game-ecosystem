# 即時觀察與個體檢視

建置後，覓食世界的可見規則展示、學習更新及固定模型觀察共用操作列。左上角標示目前控制模式；全景顯示各物種存活數與本輪出生／死亡累計。

```powershell
./scripts/world.ps1 -Mode build
./scripts/world.ps1 -Mode forage -Visible
./scripts/world.ps1 -Mode train -NewExperiment -Visible
./scripts/world.ps1 -Mode observe -ResumeFrom './artifacts/runs/<已保存執行>' -Visible
```

## 操作

- P 或「暫停／恢復」停止或恢復模擬。暫停時不推進世界步、生命循環、技能計時及模型決策；已送出的訓練批次仍可能完成處理。
- 0.5×、1×、2×、4×、8× 改變執行速度，世界步長保持不變。暫停時選速度，恢復後才套用。
- 滾輪以游標所在位置縮放；面板上的滾輪用於捲動檢視內容。「全景」復原鏡頭並取消選取。
- 點選個體開啟局部視野與檢視面板，點空白取消選取。「重建世界」可於暫停時使用，保留速度及暫停狀態；訓練模式保留 trainer 與已學策略。

個體面板顯示自身健康、能量、年齡、成長階段、繁殖冷卻、普通攻擊及出生時固定的兩個技能。技能標示冷卻、能量不足、施放中、定身或就緒；「就緒」仍須有合法目標或位置，世界不保證每次嘗試都成功。

面板列出前搖、衝鋒／遁行剩餘距離、護盾、培育、定身、減速、中毒與移動偏向。可見的命中目標、區域位置及培育食物以物種或座標辨認；最近命中回饋保留三個模擬秒。死亡或離開者自動取消選取，短暫顯示原因；重建及換輪清除舊選取與回饋。

## 個體視野

選取圈與 120° 扇形呈現自身位置、朝向與感知半徑。選取時只保留自身及視野內個體的即時畫面，操作列改為可見個體數；食物使用模型原有的徑向感知範圍。區域及投射物也只在視野內顯示。視野外敵人僅以「◇」及面板中的物種、最後位置與距今秒數呈現原有五秒警戒記憶，不顯示遠端即時位置、健康或穩定追蹤識別。

自身編號供使用者辨識選取對象，沒有加入模型觀察。可見個體的效果狀態供理解技能互動，不提供其遠端目標。切換全景後可觀察整體生態；所有畫面過濾只影響 Renderer，不改變世界、策略觀察或動作。

## 固定模型觀察

`observe` 必須指定 `-ResumeFrom`，沿用保存的配置與種子；也可指定不同 `-Seed`。來源相容性檢查與續訓相同，詳見[保存與續訓](resume-training.md)。包含本次畫面變更的重新建置會改變世界組件雜湊，舊組件模型會被保守拒絕；請保留原資料，使用目前建置另開新實驗。

固定觀察將模型複製到新的輸出目錄，以 ML-Agents inference 執行，結束時檢查三物種 checkpoint 的容量、SHA-256 與累計步數維持原值。`training.json` 標記 `operation: observe`、世界步數上限與來源；`world.jsonl` 標記 `policyMode: fixed`。來源檔案保留，世界由新一輪開始。

可見觀察預設持續到關閉；無畫面預設 512 世界步。`-Steps 128` 可限制兩者的世界步數，`-Steps 0` 僅適用可見模式。可見 Python 控制容許最長 24 小時無新決策，供長時間暫停檢視。

## 人工核對

1. 開啟 `forage -Visible`，暫停後核對時間、年齡、能量與冷卻不變；暫停中選 8×，恢復後確認加速，再改回 1×。
2. 點選個體，確認兩技能與扇形，滾輪縮放後按「全景」復原。確認選取時遠端個體隱藏、統計只含可見個體；敵人離開視野後只留最後位置，五秒後消失。
3. 使用 README 的固定技能場景，觀察前搖、命中、控制、培育或區域的目標與剩餘時間。讓選取個體死亡，確認提示及面板清除；暫停中重建，確認換輪、舊選取清除且仍暫停。
4. 分別開啟 `train -Visible` 與 `observe -ResumeFrom ... -Visible`，核對「學習更新」與「固定模型・不更新」標示；正常結束後比較 checkpoint 步數，前者可增加，後者保持不變。

## Standards

以 `93bf96c` 為比較點，兩項重複邏輯已修正：視野點判定共用 `World.CanSeePoint`，技能施放與面板共用 `SkillRules.EnergyCost`。複核後零項明文違規、零項剩餘可行動程式異味。
