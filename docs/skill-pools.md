# 三物種技能池

任務 15–17 沿用任務 14 的出生配置及 `World.Step`。每個體攜帶兩招，基本攻擊不占欄位；規則控制器可依所攜帶技能選擇施放，尚非生態學習結果。

## 技能與起始參數

以下能量、秒數及強度是可調整的原型預設，未宣稱平衡；完整參數寫入每次執行的 `config.combat`。

| 炎角／熾熱猛擊 | 10／5 | 近距離 1.5 的掃掠攻擊，傷害 26；未命中合法目標不扣成本 |
| 炎角／防禦姿態 | 10／8 | 2 秒內承受戰鬥傷害乘 0.35 |
| 炎角／威嚇咆哮 | 9／7 | 自身周圍 3 內敵人受到向外偏向 0.2，持續 2 秒，不造成傷害或封鎖攻擊 |
| 霜羽／霜縛箭 | 10／5 | 傷害 8，命中減速 1 秒，普通移速乘 0.55 |

## 動作與施放

`WorldAction.aim`、場景 `aimX/Y` 現在表示世界位置。模型的兩個瞄準輸出以地圖半徑縮放為世界位置；手動模式使用滑鼠。前搖起手固定射出方向，因此可指定預判落點，也可能射偏。咆哮、根鬚與煙幕不讀取瞄準點；培育沿用附近食物選擇規則。

技能由共用閘門檢查出生配置、各欄冷卻、能量及施放狀態。衝鋒、遁行、冰箭前搖與培育期間拒絕另一技能；無合法目標或位置時不扣施法能量、不啟動冷卻、不自動換招。若同時明確要求基本攻擊及有效技能，技能優先；無效技能不會隱含產生基本攻擊，只有原動作另有 `attack` 時才嘗試攻擊。日常移動及基礎耗能照常結算。

播種須在邊界內、未達 `foodSourceLimit`（預設 64，包含原有 16 個來源）；與食物距離至少 0.8，避開存活個體及有效陷阱。地圖沒有障礙物，其餘地面可行走。種子成熟前存量為零、不能採食或培育，成熟後才自然再生及接受培育；不即時產生可食用能量。

## 控制與持續效果

相同定身或減速只延長有效期限，不增加強度；陷阱的減速在定身結束後開始。不同控制可並存，定身不封鎖攻擊。衝鋒及遁行會被定身停止移動，尚有剩餘距離時可在解除後繼續；衝鋒仍使用自己的固定速度。

移動偏向按效果類別保留一份，相同咆哮不疊加；煙幕偏向強度 0.15，每 1.5 秒選擇下一方向，轉速上限每秒 90°。兩種偏向合併後長度不超過 0.35，再與策略移動合併，不完全接管操作。定身期間不新增、刷新或改變偏向；尚未逾時的偏向在解除後恢復。煙幕每次接觸刷新 0.6 秒偏向，因此離開後很快消退。隨機方向使用由世界種子衍生的獨立亂數序列。

煙幕內每 1 秒增加一層中毒，最多五層，並刷新 3 秒持續時間；重疊煙幕共用每個目標的加層計時，不會加速累積。離開後不新增層數，既有中毒繼續到期；五層再次施毒只刷新期限。毒傷每 1 秒依當時層數結算，每層基礎傷害 1，五層時總傷害加倍為 10。煙幕不降低攻擊傷害，不影響苔靈；中毒屬持續傷害，沒有施放當下的直接傷害。

多名培育者作用於同一食物時，再生強度維持每秒額外 4，依仍有效的施放期間延續，不逐人疊加。防禦姿態重複施加只刷新期限。

`SkillRules` 處理驗證及施法，`CombatRules` 處理攻擊、投射物及移動，`ControlEffects` 處理控制、偏向及中毒；仍由同一個世界步統一結算。`state.areas`、食物成熟狀態、個體控制／中毒狀態與事件供畫面及外部驗證讀取。

## 展示與人工核對

```powershell
./scripts/world.ps1 -Mode build
./scripts/world.ps1 -Mode forage -WorldConfig training/scenarios/world.json -Scenario training/scenarios/skills-flame.json -Visible
```

替換場景檔即可查看其他技能：

| 場景 | 核對 |
| --- | --- |
| `skills-flame.json` | 熾熱猛擊扣能量及命中，咆哮推偏敵方但不直接扣健康 |
| `skills-frost-arrows.json` | 穿透冰矢連續命中、霜縛減速、基本冰箭不減速 |
| `skills-frost-mobility.json` | 陷阱先定身後減速，霜羽向上遁行 |
| `skills-moss-growth.json` | 棕色種子成熟後變食物，才能採食及培育 |
| `skills-moss-control.json` | 定身、煙幕偏向、中毒累積至五層及煙幕結束後仍有毒傷 |

點選個體查看兩欄技能、獨立冷卻與同時存在的狀態。定身呈紫色、中毒偏綠；陷阱為藍色地面標記、煙幕為紫色區域，技能有短暫範圍圈。既有 `flame.json` 可核對衝鋒；`frost.json`、`frost-escape.json` 改用霜縛箭保留原有減速核對，`moss.json` 的舊 Shield 指令仍會拒絕。

手動模式：`./scripts/world.ps1 -Mode forage -Visible -Controller manual`，方向鍵移動、滑鼠瞄準、Q/E 轉向、S/D 選技能、A 攻擊、空白採食。規則控制器會依個體配置選擇技能，世界不替無效輸入換招。
