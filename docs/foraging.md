## 人工核對

1. 執行 `./scripts/world.ps1 -Mode build`，接著執行 `./scripts/world.ps1 -Mode forage -Visible`。
2. 確認畫面標示「規則控制・尚非學習結果」，四處大型黃色產地及零散食物隨採食縮小、變暗，閒置時再生。
3. 點選個體，確認健康及能量分開顯示；觀察採食補充能量，耗盡後健康下降、死亡後消失。
4. 使用 `-Controller manual -Visible`，以方向鍵移動、空白鍵採食，核對接近食物而未採食不會自動補充能量。
5. 執行 `./scripts/world.ps1 -Mode forage -Controller idle -Steps 8000`，在輸出 `world.jsonl` 核對 `starved`、`agent_died` 事件及健康、能量。
6. 執行 `./scripts/world.ps1 -Mode forage -ReloadRun '<輸出>/world.jsonl' -Steps 12000`，核對配置、種子、控制模式與起始狀態一致。

## 限制

- 這是規則覓食展示；繁殖、老化、戰鬥、恢復健康及正式學習由後續任務實作。
- 同時爭奪食物依個體順序分配，不保證公平或三物種共存；存量與消耗參數尚未平衡。
- 時間到或全部死亡時自動重建，維持既有執行入口；有限步數結束時不額外重建。重載從起始狀態執行，不是歷史回放。
- 可見執行已比對輸出；點選與字型呈現仍需依上述步驟人工核對。
