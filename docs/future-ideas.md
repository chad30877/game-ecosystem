# 後續構想

收錄後續構想及其討論、排入與完成狀態；本清單不是正式規格或可執行任務。每次 `grill-with-docs` 訪談先查看，與當前主題相關時提出討論，由使用者決定是否納入。

已完成的生存資源與規則式 AI 工作見[正式規格與任務](../.scratch/archive/survival-resources-and-environment/README.md)；各構想的目前狀態以個別條目為準。

## 待討論

### 果實、採集、攜帶與交付

- 狀態：討論中；2026-10-29 使用者指定與「繁殖後供給與苔靈產出差異」併入[同一輪訪談](design/reproduction-supply-and-moss.md)，尚未發佈正式規格與任務。
- 已確認：逐顆果實採相同營養與進食時間，先採入攜帶再另行進食，吃完整顆才補充飽食度；成體帶三顆、幼體一顆，採集暫占單顆，採集與進食中斷後重新計時。
- 生長與保存：非線性分散成熟，每輪抽一次有界隨機果數，不補已採走或腐爛的名額；腐爛時刻為實際成熟加固定保存時長，轉移不刷新。採光仍等本輪最後腐爛期限才休養；培育持續耗魔、加速有界且不縮短保存時長，中斷保留來源進度。生物感知粗略新鮮度，視野外只推測；腐爛直接移除，未吃完不取得營養。
- 交付與掉落：同種可交付，本輪規則 AI 主動交付只餵自己幼體；雙方停下配合，一次接收一筆、先預留一格，完成才逐顆轉移，不直接補營養。拾取與主動放下皆花時間、中斷重新計時；死亡立即掉落原有果實，任何物種可拾取，保存時間不刷新，也不成為新生長來源。
- 待釐清：行動移動與受擊中斷、同時競爭分配、養育與選果策略、感知細節及數值；仍須重新評估供給、資源收支與既有驗證。詳細決策及尚未確認的提案見訪談。
- 關係：既有養育仍是親代直接轉移飽食度；訪談已決定以果實交付替換，尚未實作。

### 繁殖後供給與苔靈產出差異

- 狀態：討論中，見[繁殖後供給與苔靈產出差異訪談](design/reproduction-supply-and-moss.md)；尚未確認實驗或調整範圍，不代表已完成長期平衡。
- 訪談決定：開發中版本變動快速，不採先圍繞現行版本完成供給診斷的提案；接受物種表現不對稱。2026-10-29 使用者指定與「果實、採集、攜帶與交付」合併討論，具體機制及實作範圍仍待確認。
- 新確認：Q5 採有限供給，不依人口自動增產，不保證後代存活；Q7 確認全苔靈族群應受環境供給約束，允許波動、衰退或滅絕，人口硬上限僅作執行保護。播種與培育的具體制衡仍在訪談。
- 技能限制：Q10–Q12 確認天然與播種共用有限生長空間，培育受單處總產速限制且不疊加；保留成熟、休養與有限來源壽命，不新增土壤肥力等資源。空間、來源生命週期與數值仍待細化。
- 來源生命週期：Q13 改為機率性播種大小型，暫以小 80%／大 20% 討論；Q15–Q16 確認來源從建立起計算壽命且到期移除未採果實、天然補生不得突破空間限制。Q14 原採額度用完即休養，2026-10-30 新增腐爛與非線性結果要求後，休養觸發及生長銜接須依訪談修訂，不能直接沿用原案。
- 證據：[07生態觀察](ecosystem-observation.md)及 Git 中的數值結果；原始場次大檔依[本次清理](artifact-retention.md)淘汰，後續對照須重新執行。
- 觀察：四來源配置在單體驗收足夠，但繁殖後仍可能出現幼體缺糧；苔靈的培育與播種可能擴大供給及後代數量。
- 待釐清：繁殖壓力、食物再生與休養、來源空間分布、掃視及舊情報選擇如何影響供給；對照方法與時機待工作方向確認後決定。觀察差異不直接證明單一原因；原生存資源輪未新增親代保護，已交付的養育機制見[幼體照顧與記憶推測](juvenile-ecology.md)。

### 同一個體內的規則接管

- 想法：PPO 控制個體時，可由規則在生存危機下接管部分決策。
- 範圍：本輪聚焦 Environment 與規則式 AI；PPO 及混合控制實驗一併延後。未來先沿用按物種分配控制器，個體內接管仍維持延後。
- 待釐清：接管與交還控制的條件、訓練及評估的一致性，以及如何區分規則保底與模型學習的效果。
- 背景：[生存資源與 Environment 訪談](design/survival-resources-and-environment.md)。

### 更多樣的技能資源成本

- 想法：技能增加後，再討論同時使用體力、魔力等不同資源的成本組合。
- 範圍：本輪特殊技能只消耗魔力，衝撞與魔法強化近戰也不採複合成本。
- 待釐清：哪些技能需要複合成本，以及與普通近戰、奔跑的差異。
- 背景：[生存資源與 Environment 訪談](design/survival-resources-and-environment.md)。

### PPO 與混合控制實驗

- 狀態：延後（deferred），沒有啟動日期。
- 既有任務：[07：探索與生存行為的多種子驗收](../.scratch/archive/dynamic-resources-and-exploration/issues/07-behavior-evaluation.md)已從 claimed 改為 deferred；保留評估工具、成本摘要與短程未達標結果。歷史模型及 PPO 回放依[本次清理](artifact-retention.md)淘汰，尚缺三次獨立訓練及正式長期模型對照，恢復時須重新建立來源。
- 想法：環境完善並經持續觀察後，再以小規模 PPO、初始策略對照與按物種混合控制檢查學習效果。
- 範圍：本輪不執行 PPO 訓練與成效比較，也不以學會生存作為本輪完成條件；沒有預定啟動日期，需待使用者另行決定。
- 待釐清：環境何時適合開始訓練、實驗預算、對照方法與學習改善指標。
- 恢復條件：使用者重新排入後，依當時環境確認規格、觀察／行動介面、配置、模型相容性與驗收門檻，再編列訓練預算；不直接沿用舊模型作為四資源環境的驗收證據。新 Environment 任務可獨立進行，完成後也不自動啟動本項。
- 背景：[生存資源與 Environment 訪談](design/survival-resources-and-environment.md)，Q25 確認即使本輪完成仍需觀察，PPO 可能很久以後才啟動。

- 狀態：未來構想；不改變 PPO 與混合控制實驗的延後狀態。
- 想法：研究共享物種策略是否可以結合族群表現回饋，促進保護幼體等有利群體的行為；群體獎勵不等同自動共享個體資訊。

### 幼體照顧的長期生態對照

- 本輪範圍：供給與果實訪談 Q6 確認本項繼續留待後續。
- 想法：以更長時間及更多固定種子分離餵養、保護與物種互動的影響。
- 依據：[短程配對觀察](juvenile-ecology.md)中部分照顧組的幼體或親代死亡；因行為分歧及樣本小，尚無法歸因。
- 待釐清：如何在保留相同初始條件下量測完整生命、食物供給與養育代價；不預設養育必然有利。

### 決策間隔與長期回報

- 狀態：未來構想，本輪只分析並記錄；不改變 PPO 與混合控制實驗的延後狀態。
- 動機：目前每 0.02 秒決策、工具鏈 gamma 為 0.99，遠期回報折扣很快；希望較長期結果能影響策略。折扣時間尺度不等同記憶長度。
- 選項：評估每 0.2 秒決策，或保留高頻決策並提高 gamma；尚未選定。維持 0.99 時回報半衰期由約 1.38 秒增為 13.79 秒；0.02 秒搭配約 0.998995 可達相同每秒折扣。
- 待釐清：期望規劃的模擬時間、反應精度、動作維持與中斷、回報累積、lambda、軌跡長度及樣本預算；需區分降低決策頻率與拉長折扣時間的效果，不保證改參數就能學會長期規劃。
- 背景與優缺點：[觀察體驗與決策時間尺度訪談](design/observation-experience.md)。

## 維護方式

- 新構想以簡短條目記錄意圖與待釐清問題，保留使用者尚未決定的選項。
- 納入某次訪談後標示「討論中」並連結訪談；正式排入工作後標示「已排入」並連結 `.scratch` 規格或任務，細節以該處為準。
- 完成或放棄時更新狀態及結果連結，供後續訪談辨識。
