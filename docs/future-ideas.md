# 後續構想

收錄尚未納入本期的想法；本清單不是正式規格或可執行任務。每次 `grill-with-docs` 訪談先查看，與當前主題相關時提出討論，由使用者決定是否納入。

## 待討論

### 幼體與成體的能力差異

- 想法：後續設計成長階段的能力差異，目前同物種幼體與成體的攻擊規格相同。
- 範圍：本期資源動態化、探索與掃視維持既有幼體戰力。
- 待釐清：哪些能力隨成長改變，以及對幼體覓食、撤退、成活率與親代保護的影響；尚未決定加入親代保護。
- 背景：[資源動態化與主動探索訪談](design/dynamic-resources-and-exploration.md)。

## 維護方式

- 新構想以簡短條目記錄意圖與待釐清問題，保留使用者尚未決定的選項。
- 納入某次訪談後標示「討論中」並連結訪談；正式排入工作後標示「已排入」並連結 `.scratch` 規格或任務，細節以該處為準。
- 完成或放棄時更新狀態及結果連結，供後續訪談辨識。
