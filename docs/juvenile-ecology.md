# 幼體照顧與記憶推測對照

## 已交付機制與文件入口

幼體成長、親代養育與記憶推測的七項任務已完成，歷史規格與驗收見[歸檔索引](../.scratch/archive/juvenile-care-and-memory/README.md)。本文件保留仍有效的行為摘要及觀察限制，歸檔不代表已完成長期生態平衡。

- 幼體健康上限、普通攻擊及指定技能隨成長變化；舊回放保留當時能力規則，不以新規則改寫歷史。
- 食物與親子情報依最後觀察及經過時間推測，視野外不更新世界真值；重新看見後修正。失聯搜尋不無限重複同一筆已搜尋情報。
- 餵養由親代飽食度直接轉移給幼體，核對付出與取得；超距、成年、死亡或親代戰鬥等停止條件會中止，不退還已轉移營養。
- 親代保護依可見子女、威脅、能力與自身狀況選擇；威脅消失、失去視線或自身危急時可終止與撤退，不保證親代或幼體必然存活。
- 操作與共同觀察見[四資源與診斷](survival-resources.md)，本輪後續煙幕避險的影響另見[煙幕感知](smoke-awareness.md)。下列短程報告是當時版本的證據，不當作後續版本的重新驗收。

## 短程對照紀錄

2026-10-28，使用 survival-v13、純規則控制與正式世界入口。觀察不是完整生態平衡驗收，也不證明養育必然改善存活。

## 配對配置

三種情境各以種子 101、102、103 進行有／無養育配對，共 18 場；每場 1500 步、0.02 秒／步，即 30 秒。起始各有一對炎角、霜羽、苔靈親子（共六個體），幼體一歲、親代與幼體飽食 70／30；關閉繁殖，老化及成長保留。充足情境三處各 30 食物、有限情境一處 4 食物，可見威脅情境把不同物種相鄰排列且一處 4 食物。食物可再生、培育及播種，充足僅是初始供給。兩組僅 `disableCare` 不同，停用親代保護、餵養、失聯搜尋及幼體靠近親代；其他世界規則相同。隨機種子相同不代表分歧後隨機序列或環境仍相同。

## 效能

同一執行檔以 `disableMemoryPrediction` 切換食物可能恢復與親子外推；停用時仍保留記憶並以最後觀察值表示，不提供虛構的視野外真值。每組相同 30 個體及 27 筆親子關係、1000 步、0.02 秒，固定種子 101–103，純規則控制，含逐步 JSON 與回放封裝。各場峰值 204–315 筆食物記憶、1417–1920 筆區域記憶；行為分歧使實際記憶量與輸出大小不同。

| 種子 | 推測啟用秒 | 推測停用秒 |
| --- | ---: | ---: |
| 101 | 15.01 | 14.76 |
| 102 | 16.27 | 16.72 |
| 103 | 16.07 | 16.32 |

這是含程序啟動、逐步輸出、回放封裝的整體時間，不是獨立推測函式成本；固定啟用後停用的順序、快取和行為分歧均可能影響結果，不能據此排除小幅效能差異。沒有觀察到足以支持明顯成本增加的證據，故未宣稱瓶頸。詳細數據見 [效能資料](juvenile-benchmark-results.json)。環境為 Windows 10.0.26200、Intel i5-12500H（12 核／16 執行緒）、Unity 6000.0.85f1、Python 3.10.12，無畫面 Null Device。

## 重現與核對

```powershell
./.venv/Scripts/python.exe training/juvenile_ecology.py artifacts/juvenile-ecology-rerun
./.venv/Scripts/python.exe training/juvenile_benchmark.py artifacts/juvenile-benchmark-rerun
$replay = Get-ChildItem artifacts/juvenile-ecology-20261028/abundant-101-care -Recurse -Filter episode-1.replay.jsonl | Select-Object -First 1
./scripts/world.ps1 -Mode replay -ReplayFrom $replay.FullName -Visible
```

輸出目錄須不存在。原始逐步資料及全部配對回放保存於 `artifacts/juvenile-ecology-20261028/`，效能配置與輸出位於 `artifacts/juvenile-benchmark-20261028/`。回放中選擇親代查看實際餵養／保護，再對照幼體最後觀察、推測與世界真值；例如充足 101 包含死亡與保護事件，不只保留成功場次。切換畫面前後跳轉核對歷史狀態，不把現況作為當時觀察。

Unity 建置及 128 步 bridge 通過；同一威脅場景可見與無畫面 101 影格逐值一致。充足 101 回放跳轉 0→300→1499→300→0，五個快照均與逐步紀錄一致；v9–v12 舊回放、跨成年技能、培育交接、失聯、餵養中斷及保護終止的固定核對見各前置任務完成紀錄。整合後再次執行跨成年與培育場景。未執行 PPO、混合控制或果實機制。

初始配置、樣本短及關閉繁殖均限制推論；後續可延長觀察並分離保護、餵養和物種互動，參考 [後續構想](future-ideas.md)。
