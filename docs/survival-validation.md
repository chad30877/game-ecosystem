## 重現與人工核對

```powershell
foreach ($species in @('Flame','Frost','Moss')) {
    foreach ($seed in 101..110) {
        ./scripts/world.ps1 -Mode forage -WorldConfig "training/scenarios/survival-isolation/$species.json" -Scenario training/scenarios/survival-isolation/layout.json -Controller rules -Steps 30000 -Seed $seed -OutputRoot "artifacts/survival-ticket06/rerun/$species-$seed"
    }
}
```

種子 101 加 `-RecordEpisodes 1` 保留代表回放；本次產物在 `artifacts/survival-ticket06/matrix/<物種>-<種子>/forage-*/`。回放為每物種 30001 影格，約 234–238 MB。人工選取任一代表檔執行：

```powershell
$replay = Get-ChildItem 'artifacts/survival-ticket06/matrix/Flame-101/*/episode-1.replay.jsonl'
./scripts/world.ps1 -Mode replay -ReplayFrom $replay.FullName -Visible
```

切換 Frost、Moss，拖曳至 0、240、480、600 秒再反向，點選個體核對進食、四資源及舊情報；播放／暫停、調速可自行檢視。即時觀察沿用同配置，加 `-Visible`。本次有執行可見世界並逐值核對狀態，未宣稱已人工檢視所有畫面。
