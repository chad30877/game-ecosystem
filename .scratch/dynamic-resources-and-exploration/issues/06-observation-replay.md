# 06：資源、記憶與掃視的歷史觀察

**What to build:** 使用者能錄下一場新世界並前後拖動回放，檢查食物更替、個體舊情報、探索獎勵與掃視介入，區分世界真值和個體當時所知。

**Blocked by:** 05：可保存續訓的探索學習循環。

**Status:** ready-for-agent

- [ ] 完整紀錄涵蓋資源新增／消失及恢復狀態、個體記憶、獎勵分項與掃視來源，並帶規則版本及完整配置。
- [ ] 即時全景與個體檢視、歷史回放均使用正確資料語意；個體舊情報不被全景真值覆寫。
- [ ] 拖動跨越來源消失、個體出生死亡及記憶更新時，快照與歷史記錄一致；回放不執行模型或重新發獎勵。
- [ ] 介面以既有狀態視覺與簡短標記呈現，能辨識主動轉向及系統補看，不添加重複說明。
- [ ] 不相容歷史記錄明確拒絕且保留原檔；新格式正反向拖動、暫停、調速及個體選取可人工核對。
- [ ] 記錄新增資料的容量成本，完成新版本錄製到回放的實際往返。
