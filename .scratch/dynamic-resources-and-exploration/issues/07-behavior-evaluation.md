# 07：探索與生存行為的多種子驗收

**What to build:** 使用者取得固定場景、多種子對照與代表回放，判斷動態環境下是否改善覓食與生存，而不是只增加移動或系統掃視。

**Blocked by:** 06：資源、記憶與掃視的歷史觀察。

**Status:** claimed

- [ ] 固定場景涵蓋安全定居掃視、食物枯竭找替代、舊情報撲空後調整、低能量優先補給及身後新威脅；分開報告規則與學習策略結果。
- [ ] 至少十組固定評估種子，使用相同世界配置比較初始、規則與訓練策略；基本掃視設定一致，保存精確初始模型及實驗來源。
- [ ] 先實測訓練成本並制定可執行預算，採多次獨立訓練檢查穩定性；評估期間凍結模型，不混用介面或規則版本。
- [ ] 評估時長足以涵蓋來源更替、休養與情報過時；指標定義及量化門檻在執行前固定，不依結果挑選種子。
- [ ] 分物種報告存活、飢餓、採食、探索覆蓋、重複路徑、主動與保障掃視；對重複移動區分有收益補給與無收益繞圈。
- [ ] 報告平均、種子間變異、未完成生命樣本、訓練預算及限制，附可重現的代表回放。
- [ ] 資訊獎勵總上限與無重複領獎符合規格；若行為未通過或改善證據不足，保持任務未完成及學習效果未驗證，記錄後續調整。
- [ ] 建置、bridge、技能、生命循環、保存續訓及回放既有有效檢查通過；不以刪除既有驗證或新增未核准測試檔完成驗收。
