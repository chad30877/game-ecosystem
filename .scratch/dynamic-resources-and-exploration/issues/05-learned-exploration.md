# 05：可保存續訓的探索學習循環

**What to build:** 三物種在完整動態環境中依個體記憶學習覓食與探索，取得有限首次觀察獎勵，並可保存、續訓及以固定模型觀察。

**Blocked by:** 02：自然資源更替與播種來源壽命；04：合理定居時的基本掃視保障。

**Status:** ready-for-agent

- [ ] 首次區域觀察有獨立資格紀錄，與會淘汰的環境記憶分開；每個體總獎勵受配置上限限制。
- [ ] 原地轉圈、往返、等待情報過時與記憶淘汰皆不重置獎勵資格；同一步不得重複領取同區域。
- [ ] 存活／繁殖／死亡與探索輔助獎勵分項記錄，不對移動距離或重訪發分，初值與調整理由可追溯。
- [ ] 三物種新觀察完成 PPO 更新及模型匯出；學習策略自行選擇移動，不套用規則展示的覓食決策。
- [ ] 同版本保存、續訓及固定模型觀察成功，配置與版本完整核對；舊模型拒絕且原檔保留。
- [ ] 重建世界保留策略但清空環境記憶，續訓新世界不繼承上輪情報，全新實驗清除策略。
- [ ] 保存精確初始權重及訓練種子，實測時間、記憶體與紀錄成本，準備後續學習對照；短訓練只標示技術往返成功。
