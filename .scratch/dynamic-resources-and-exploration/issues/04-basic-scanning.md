# 04：合理定居時的基本掃視保障

**What to build:** 生物在原地採食或停留時仍會補看長時間未觀察的方向；眼前有緊急求生需求時可暫緩，解除後恢復。

**Blocked by:** 03：方向食物視野與個體探索記憶。

**Status:** ready-for-agent

- [ ] 方向新鮮度只依合法觀察更新，超時後向較舊方向補看；模型已主動更新時不多餘介入。
- [ ] 既有原地轉向、轉速上限與獨立移動維持，不增加頭部動作或固定巡邏。
- [ ] 採食不能永久阻止掃視；緊急條件、延後原因與恢復條件具體配置並記錄，只使用個體可知資訊。
- [ ] 規則展示、學習訓練與固定模型觀察使用相同掃視仲裁；記錄原始動作、實際轉向與介入來源。
- [ ] 固定場景展示安全定居後看見持續存在的身後威脅；另驗證主動轉向不介入、緊急暫緩及解除後補看。
- [ ] 可見／無畫面行為一致，保留攻擊與移動語意；驗收不要求固定時間完整轉一圈，也不宣稱所有瞬間敵人都能被發現。
