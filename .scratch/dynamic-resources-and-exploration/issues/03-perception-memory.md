# 03：方向食物視野與個體探索記憶

**What to build:** 使用者能看見生物透過轉身發現食物，離開視野後依有限的舊情報行動，並在重看時修正撲空或變化的資訊。

**Blocked by:** 01：可觀察的食物枯竭與恢復。

**Status:** ready-for-agent

- [ ] 食物遵守相同方向視野與距離邊界，背後食物不再直接送給規則展示或學習策略。
- [ ] 可見與記憶資料區分；視野外不刷新存量、狀態或存在，重新觀察才更新或撤銷失效食物情報。
- [ ] 區域與食物記憶有容量及過時設定，優先保留近期威脅及有用食物資訊；當前生物視野不因記憶上限被截斷。
- [ ] 個體各自累積，死亡移除、新生與重建清空；共享策略不共享環境情報。
- [ ] 規則展示可依記憶返回食物、撲空後換目標，無已知食物時依未知／過時資訊選擇；不固定巡邏。
- [ ] 新觀察送達三物種 Python 策略並完成短 bridge 驗證；全景真值不進入個體觀察，舊介面模型明確拒絕。
- [ ] 使用固定動作改變視野內外食物狀態驗證過時與修正，不必等待自然更替；人工個體檢視與事件可核對，不新增測試檔。
