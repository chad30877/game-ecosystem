## 驗收條件

- [x] 逐一核對一般可見／無畫面、直接 Player、腳本、必要 bridge、固定模型觀察與驗收工具的記錄預設、來源資料和輸出位置；只有明確要求才輸出完整或詳細診斷。
- [x] ReloadRun 等必要重跑入口使用新來源資訊，與快照回放分開；模型及 PPO 不新增歷史相容、訓練或成效實驗。
- [x] 短程固定情境涵蓋輕量統計正確、多輪與提前停止、前後跳轉、錯建置／損壞拒絕、初始化／執行中失敗及整批封裝成功判定。
- [x] 整合驗證五次／一次、錄製位於最近五次外、失敗不替換、建置切換、並行使用與清理界線；來源冗餘刪除不遺失必要資訊。
- [x] 完成適用建置、必要 bridge 及可見操作，核對記錄模式未改變同建置同配置同種子結果；不跑六場長期生態或 PPO。
- [x] 若修改 .ps1，保留 UTF-8 BOM 並附 PowerShell 5.1 執行 scripts/check-world-script.ps1 的結果；記錄所有實際驗證命令、版本、結論與限制。
- [x] 整合證據在可能觸發淘汰前另存必要部分，結論保存至可追溯報告，不能因清理而以空目錄宣稱檢查通過。

## 人工測試方式

按報告命令一般啟動、明確錄製、多輪重建、提前停止、播放及換建置；確認可見效果與資料／保留狀態一致。這是後續驗收方向，本次未執行；實作後補入確切命令及結果。
