## 驗收條件

- [x] 無法建立必要目錄／檔案或初始寫入失敗時明確回報啟動失敗，不宣稱已有正常資料。
- [x] 在世界推進後注入主紀錄或完整來源寫入失敗，後續出生死亡同步、世界更新與畫面仍繼續，失敗的資料寫入不持續反覆干擾世界。
- [x] 可見介面顯示簡短的不完整狀態，無畫面／驗收入口可辨識資料失敗；回報不只依賴已寫入失敗的檔案。
- [x] 結尾寫入、關閉或封裝失敗時不留下可被誤認為完整的成功狀態，不取代上一份成功錄製。
- [x] 崩潰／強制終止的殘留資料可辨識為未完整結束，不猜成正常停止；只保留實際寫出的內容，不新增殘缺回放搶救。
- [x] 用可重現的隔離故障情境驗證初始化與執行中行為，明列世界是否繼續與資料是否有效兩個結果。

## 人工測試方式

分別模擬啟動前無法寫檔及執行中寫入失敗；前者應啟動失敗，後者應看得到世界繼續與資料不完整提示。這是後續驗收方向，本次未執行；實作後補入確切命令及結果。
