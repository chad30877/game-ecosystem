## 切片與依賴依據

- 01 從世界感知一路交付共同觀察、簡潔狀態顯示及回放核對，可獨立驗證。
- 02 使用 01 的個體情報，交付可觀看及回放的避險行為；不需要等待煙幕圖形或版面修改。
- 03 使用既有世界煙幕與觀察視角完成圖形裁切，04 使用既有觀察介面完成配置；兩者均不以新的煙幕感知資料作為前置。
- 05 使用全部功能完成整合觀看流程、跨功能回歸、成本報告與結案；不是前四項基本測試的唯一入口。
- 沒有已確認必須先完成的廣泛重構。必要的小幅整理隨功能切片進行；若實作發現無法獨立維持建置的廣泛變更，再評估展開／遷移／收斂，不能預先擴大範圍。

人工核對：逐項對照規格、任務驗收與 Q1–Q20 訪談決定；確認未納入 PPO 訓練及決策頻率調整。
