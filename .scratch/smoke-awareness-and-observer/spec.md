# 煙幕感知、避險與觀察體驗規格草案

狀態：needs-info；Q1–Q20 的功能決策已確認，待使用者核對整體規格與任務拆分後正式發佈。此草案不是實作啟動指令。

背景：[設計訪談](../../docs/design/observation-experience.md)。術語依 [GLOSSARY](../../GLOSSARY.md)。

## 目標與範圍

生物能在符合視野條件時察覺煙幕，依觀察與短期記憶避開有害範圍；觀看者能辨識煙幕且不被工具列、右側面板遮擋世界。即時觀察與回放一致。

不調整模擬步長、決策間隔、gamma、煙幕施毒規則或其他技能效果；不啟動 PPO、混合控制、果實機制、長期生態平衡工作。0.2 秒決策留在 [future-ideas](../../docs/future-ideas.md)。

## 煙幕察覺與資料

- 沿用個體的方向與視距。煙幕圓形與視野扇形相交即察覺，中心不必可見；完全不可見且未曾察覺時沒有情報。
- 先用圓心距離大於視距加煙幕半徑排除，再以圓心至扇形的最近距離判斷相交，不建立每個個體的裁切網格或逐點抽樣。
- 察覺後提供完整圓心、半徑、對自身是否有害、目前可見或記憶狀態，以及距最後觀察的時間。允許從局部可見得知完整範圍，但畫面仍只呈現可見部分。
- 不額外提供施放者身分、世界精確失效時間或視野外實況。內部識別煙幕的 ID 不代表向策略揭露施放者。
- 個體各自保存情報，規則控制器與學習控制器使用同一份可感知資料；不得在規則避險中直接查詢未知煙幕真值。
- 觀察介面新增資料須記錄欄位、正規化、容量與截斷規則，以及版本相容性；不得將不相容舊模型默認為可用。本輪只驗證介面，不訓練模型。

## 煙幕記憶

- 離開視野後保留至最後看見後 5 秒模擬時間，再次看見更新資料與時間。
- 原本範圍重新可觀察且確認煙幕已不存在時，提早清除；單純轉頭看不見不算確認消失。
- 視野外煙幕消失時不直接刪除記憶，記憶可短暫過時；不能用世界失效時間讓個體提前知道。
- 即時顯示與回放需能區分目前可見、記憶及情報年齡。記憶不畫成目前仍存在的實體煙幕，不因倒轉回放而帶入未來資訊。

## 規則避險

- 一般移動以局部方向調整避免進入已知有害煙幕，不做完整路徑搜尋；同種煙幕沿用既有無毒規則，不一律避開。
- 身處已知有害煙幕時，離開優先於採食、餵養、培育與主動攻擊；不繞過既有動作限制或物理效果。
- 親代保護須考慮煙幕，不為保護而無條件衝入。
- 僅在既有求生邏輯已判定需要緊急逃命時允許穿越：有可行安全方向優先採用，否則採較能脫離眼前威脅的方向。
- 需處理圓心位置、重疊煙幕、邊界與過時記憶，不產生無效方向。未承諾全域最短路徑、最佳路徑或永遠不中毒。
- 保留可核對的簡短決策原因，避免用冗長說明取代可觀察狀態。

## 煙幕呈現

- 全知視角呈現完整煙幕；個體視角將填色與邊線裁切至視野內，不以中心點決定整片顯隱，不增加視野外警告。
- 半透明填色與清楚邊線對準實際作用範圍；生物、食物及多片重疊處仍可辨識。
- 顯示裁切服務目前觀看視角，不影響施毒判定，也不要求每個生物各渲染一張畫面。
- 同時覆蓋即時觀察與回放的建立、消失、進出、暫停及跳轉。

## 觀察介面配置

- 頂部工具列與展開的右側面板各自保留空間，世界使用剩餘區域。
- 面板可收合；首次選取個體時展開，手動收合後換選個體仍保持收合，直到手動展開。偏好只保留於本次執行。
- 收合不取消選取或退出個體視角。回到全景且無詳細資料時釋放右側空間。
- 全景完整容納地圖；個體模式切換面板時保持相機中心與縮放尺度，正確更新點選與縮放的座標映射。
- 1280×720、960×540 均保留可操作的世界區域。面板隨視窗縮小、內容可捲動、工具列必要時換行，不退回覆蓋世界。
- UI 點擊不得穿透為世界選取；狀態與必要控制可達，文字精簡。

## 驗收與量測

- 使用固定配置及指定動作驗證：遠處、背後、中心不可見而邊緣可見、相切、身在煙幕內、圓心、重疊煙幕、同種／異種、失去視野、5 秒到期、重新觀察消失。
- 用相同觀察資料核對規則與學習介面；驗證一般繞避、離開優先、緊急穿越、親代保護與過時記憶。
- 固定狀態或固定動作下對照修改前後的世界結果，區分規則行為變化與意外改動世界規則。
- 兩種驗收尺寸檢查面板開合、換選、全景、視窗調整、點選與縮放；即時與回放均檢查，回放前後跳轉不殘留未來資訊。
- 記錄固定配置、種子、生物數、煙幕數、模擬時間與量測方式；分別量測感知／避險與可見渲染成本，報告基準、差異及限制，不以推論次數宣稱整體效能改善。先量測，不預設加入複雜索引。
- 建置、既有相關檢查及必要的場景驗證皆完成後才結案；各任務記錄人工重現方式與結果，不只核對可啟動。
- 若資料格式變更，記錄舊回放可讀範圍與不支援情況，不為舊資料虛構過去的煙幕情報。
- 每次改動以繁體中文提交；全部驗收與結案後整份功能資料夾移至 archive、更新引用，將有效知識整合正式文件。
