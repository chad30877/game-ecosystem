# 02：規則煙幕避險

## What to build

讓觀看者能在固定情境中看到生物依已知煙幕繞避、離開或緊急穿越，並在即時觀察與回放核對簡短決策原因；僅依個體情報調整局部移動。以[規格](../spec.md)為準。

## Blocked by

01：煙幕察覺、記憶與共同觀察

## Status

claimed

## 驗收條件

- [ ] 平時避開有害範圍，同種煙幕不一律迴避。
- [ ] 離開優先於採食、餵養、培育、主動攻擊，保護不無條件進入煙幕。
- [ ] 僅既有緊急逃命允許穿越，安全方向可行時優先使用。
- [ ] 圓心、重疊、過時記憶與既有動作限制不造成無效行為，具固定場景證據。
- [ ] 即時與回放可核對相同行為及決策原因；固定動作對照確認未改施毒與世界規則。
