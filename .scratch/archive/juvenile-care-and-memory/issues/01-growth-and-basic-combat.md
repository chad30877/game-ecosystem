# 01：幼體成長與普通攻擊

**What to build:** 使用者從現有世界入口觀察新生幼體以自身上限滿健康出生，健康上限及普通攻擊隨年齡由成體的 30% 線性增至完整能力，並能分辨恢復、飢餓、成年及老死。

**Blocked by:** 無。

**Status:** resolved

## 驗收條件

- [x] 新生年齡零、健康為成長階段上限的滿值，體力／魔力滿值、飽食度沿用新生配置；成人起始及既有繁殖支出不改變。
- [x] 健康上限與炎角基本近戰、霜羽基本遠程傷害在出生、半成長及成年分別按成長比例可核對；初值 30%、成年 30 模擬秒、壽命 240 模擬秒均可調，成年後不超過完整能力。
- [x] 上限成長不直接補健康；自動／營養恢復、飢餓傷害及健康比例按當前上限與既有條件結算，不產生負值、超上限或已死亡個體復活。
- [x] 正常老化推進成長；缺糧不直接暫停成長，停用老化則年齡和成長停止。移動、感知、採食、體力與魔力基本上限不因年齡縮放。
- [x] 從正式入口的配置、場景或實際出生重現必要年齡與資源邊界；狀態、精簡個體檢視與回放呈現成長及有效健康上限，保持版本辨識，舊資料相容性不被誤報。
- [x] 固定條件核對健康增加與恢復區別，觀察未受傷幼體健康可能落後上限及成年後繁殖條件；執行相關既有有效檢查並記錄人工操作，不新增未經核准的測試檔。
