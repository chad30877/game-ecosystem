# 03：食物記憶推測與回訪

**What to build:** 生物根據自己最後看見的食物狀態與時間，推測休養、恢復中或未成熟來源可能已可採食；缺少較可靠食物時回訪，並依重新觀察修正。

**Blocked by:** 無。

**Status:** resolved

## 驗收條件

- [x] 對最後看見為休養、恢復中或未成熟的食物，以可調 30 模擬秒概略等待推測可能可採食，不估算視野外現有存量或讀取真實剩餘時間、被採食及存在狀態。
- [x] 缺少較可靠可採食來源時可將推測位置列為探索目標；危險與眼前可靠食物可優先，未達估計時間不把推測當作已觀察真值。
- [x] 回訪仍休養時更新觀察並重新等待；來源已消失且位置重新可見時撤銷記憶；不對同一已確認舊情報立刻反覆折返。更新後照實選擇可採食、探索或其他生存行動。
- [x] 沿用方向視野、有限食物／區域記憶與掃視，不讓規則 AI 或未來策略取得視野外真值；共同觀察可辨最後觀察與推測，執行記錄及回放可與世界真值對照。
- [x] 透過正式入口及固定動作重現食物視野外恢復、被吃掉、消失及推測錯誤，涵蓋重新觀察和生存優先；資料版本識別正確、相容舊回放保留、不相容資料明確提示。
- [x] 保留既有記憶、掃視、來源週期、bridge 及回放有效檢查，記錄可見人工重現方式，不新增未經核准的測試檔。

## 完成紀錄

- 已實作依最後觀察與可調等待時間推測可能恢復，規則控制在缺少已知可採食來源時回訪；共同觀察、個體檢視及紀錄保留推測與最後觀察。新執行與模型版本為 survival-v10，回放支援 v9、v10。
- Unity 建置成功；固定種子 1、0.1 秒步長、3 秒推測等待的正式世界場景中，食物第 1 步進入休養、最後於 2.3 秒看見，6 秒時推測、14 秒重見仍休養時清除推測並更新時間。恢復中及未成熟場景也在離開視野並等待後出現推測、重見後清除。來源 8 秒消失的對照場景於回訪時移除記憶；規則控制有 138 步選擇推測回訪。Python bridge 執行 128 步成功；v9 舊回放及 v10 新回放可前後跳轉，Python 拒絕未知版本。證據與場景位於 `artifacts/juvenile-food-memory-20261028/`（不納入版本庫）。
- 人工測試：用 `scripts/world.ps1 -Mode forage -Visible -WorldConfig <config.json> -Scenario <scenario.json>` 執行證據目錄中的場景，點選個體觀察食物記憶及推測；以 `-Mode replay -Visible -ReplayFrom <episode-1.replay.jsonl>` 暫停並往返推測前後影格。
- 視野外採食場景中，觀察者保留最後的 4.45 食物量，直到第 140 步再次看見才修正；規則控制在第 90 步有推測來源時選擇眼前可採食來源，弱勢爭食場景在第 86 步有推測時撤退。休養來源重見後重新等待；回放先後跳至第 60、140、60 影格，記憶資料與原始影格逐欄一致。
