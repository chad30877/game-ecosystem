# 煙幕感知、避險與觀察體驗規格

狀態：resolved。2026-10-29 使用者以 implement 啟動實作，五項任務已完成驗收並結案；先前僅發佈文件的限制已由本輪指令解除。

背景：[設計訪談](../../../docs/design/observation-experience.md)；執行依[任務索引](README.md)，領域用語依[術語表](../../../GLOSSARY.md)。

## Problem Statement

觀看者無法可靠辨識煙幕危險範圍，可能看到生物進入未顯示的煙幕後直接中毒；右側面板與頂部工具列覆蓋世界，妨礙觀察。生物目前也沒有煙幕範圍情報，無法依已見煙幕進行避險。使用者希望改善觀看體驗，並讓生物在符合視野條件後知道煙幕、短暫記住及合理避開。

## Solution

煙幕與個體視野相交時，生物取得完整範圍及有害性，失去視野後保留 5 秒煙幕記憶；規則 AI 依已知情報避險，緊急逃命允許穿越。畫面以清楚填色及邊線呈現煙幕，個體視角僅顯示視野內部分。工具列與可收合面板使用獨立空間，即時觀察與回放提供一致體驗。

## User Stories

1. 作為觀看者，我希望煙幕範圍清楚可見，以便在生物進入前辨識危險。
2. 作為觀看者，我希望全知視角顯示完整煙幕，以便理解世界中的作用範圍。
3. 作為個體視角觀看者，我希望只看見視野內的煙幕部分，以便保留視野限制。
4. 作為個體視角觀看者，我希望煙幕邊緣可見時不因中心不可見而整片消失，以便正確判讀接觸。
5. 作為觀看者，我希望煙幕半透明且邊線清楚，以便仍能辨識生物與食物。
6. 作為觀看者，我希望多片煙幕重疊仍可辨識內容，以便追蹤個體行動。
7. 作為生物，我希望煙幕任何部分進入視野時即可察覺，以便在接觸前作出反應。
8. 作為生物，我希望察覺後取得圓心與半徑，以便依完整範圍選擇移動方向。
9. 作為生物，我希望察覺時知道煙幕對自身是否有害，以便避免無謂繞避。
10. 作為生物，我希望未曾察覺且不可見的煙幕不成為已知情報，以便維持局部感知。
11. 作為生物，我希望失去視野後保留 5 秒煙幕記憶，以便轉頭後仍能避險。
12. 作為生物，我希望再次看見煙幕時更新記憶，以便使用最近的觀察。
13. 作為生物，我希望重新觀察並確認煙幕消失時清除記憶，以便不再繞避已確認安全的位置。
14. 作為生物，我希望視野外的煙幕記憶可能過時，以便不依賴未觀察的世界真值。
15. 作為規則控制生物，我希望一般移動避開已知有害煙幕，以便減少主動進入危險。
16. 作為規則控制生物，我希望身處煙幕時先離開，再採食、餵養、培育或主動攻擊，以便優先保護自身。
17. 作為親代，我希望保護幼體時也考慮煙幕，以便不無條件衝入危險。
18. 作為逃命中的生物，我希望有安全方向時優先使用、必要時允許穿越煙幕，以便不被絕對禁區困住。
19. 作為同種生物，我希望不把對自身無毒的煙幕一律視為禁區，以便保持合理活動。
20. 作為控制器整合者，我希望規則與學習控制器使用同一份煙幕情報，以便維持觀察契約一致。
21. 作為觀看者，我希望能區分可見煙幕情報、記憶與情報年齡，以便理解避險依據。
22. 作為觀看者，我希望看見簡短決策原因，以便理解生物繞避、離開或穿越的選擇。
23. 作為觀看者，我希望工具列與面板不遮住世界，以便完整觀察可操作區域。
24. 作為觀看者，我希望首次選取個體時展開面板，以便查看個體狀態。
25. 作為觀看者，我希望手動收合後換選個體仍維持收合，以便保留觀看空間。
26. 作為觀看者，我希望收合不取消選取或退出個體視角，以便持續追蹤同一個體。
27. 作為觀看者，我希望全景且沒有詳細資料時釋放右側空間，以便完整觀看地圖。
28. 作為觀看者，我希望面板開合時個體視角保持中心與縮放尺度，以便避免畫面跳動。
29. 作為窄視窗觀看者，我希望兩種驗收尺寸下控制仍可達、世界仍可操作，以便使用較小視窗。
30. 作為觀看者，我希望視窗大小改變後點選與縮放仍正確，以便操作符合畫面位置。
31. 作為回放觀看者，我希望暫停與前後跳轉顯示當時煙幕及情報，以便不混入未來狀態。
32. 作為驗收者，我希望以固定場景、同一世界入口核對介面與行為，以便重現功能結果。
33. 作為維護者，我希望得知新增感知、避險及渲染的實測成本，以便根據證據判斷是否需要優化。
34. 作為既有資料使用者，我希望觀察及回放版本相容性有明確說明，以便不誤用舊模型或虛構歷史情報。

## Implementation Decisions

### 煙幕察覺與資料

- 沿用個體的方向與視距。煙幕圓形與視野扇形相交即察覺，中心不必可見；完全不可見且未曾察覺時沒有情報。
- 先用圓心距離大於視距加煙幕半徑排除，再以圓心至扇形的最近距離判斷相交，不建立每個個體的裁切網格或逐點抽樣。
- 察覺後提供完整圓心、半徑、對自身是否有害、目前可見或記憶狀態，以及距最後觀察的時間。允許從局部可見得知完整範圍，但畫面仍只呈現可見部分。
- 不額外提供施放者身分、世界精確失效時間或視野外實況。內部識別煙幕的 ID 不代表向策略揭露施放者。
- 個體各自保存情報，規則控制器與學習控制器使用同一份可感知資料；不得在規則避險中直接查詢未知煙幕真值。
- 觀察介面新增資料須記錄欄位、正規化、容量與截斷規則，以及版本相容性；不得將不相容舊模型默認為可用。本輪只驗證介面，不訓練模型。

### 煙幕記憶

- 離開視野後保留至最後看見後 5 秒模擬時間，再次看見更新資料與時間。
- 原本範圍重新可觀察且確認煙幕已不存在時，提早清除；單純轉頭看不見不算確認消失。
- 視野外煙幕消失時不直接刪除記憶，記憶可短暫過時；不能用世界失效時間讓個體提前知道。
- 即時顯示與回放需能區分目前可見、記憶及情報年齡。記憶不畫成目前仍存在的實體煙幕，不因倒轉回放而帶入未來資訊。

### 規則避險

- 一般移動以局部方向調整避免進入已知有害煙幕，不做完整路徑搜尋；同種煙幕沿用既有無毒規則，不一律避開。
- 身處已知有害煙幕時，離開優先於採食、餵養、培育與主動攻擊；不繞過既有動作限制或物理效果。
- 親代保護須考慮煙幕，不為保護而無條件衝入。
- 僅在既有求生邏輯已判定需要緊急逃命時允許穿越：有可行安全方向優先採用，否則採較能脫離眼前威脅的方向。
- 需處理圓心位置、重疊煙幕、邊界與過時記憶，不產生無效方向。未承諾全域最短路徑、最佳路徑或永遠不中毒。
- 保留可核對的簡短決策原因，避免用冗長說明取代可觀察狀態。

### 煙幕呈現

- 全知視角呈現完整煙幕；個體視角將填色與邊線裁切至視野內，不以中心點決定整片顯隱，不增加視野外警告。
- 半透明填色與清楚邊線對準實際作用範圍；生物、食物及多片重疊處仍可辨識。
- 顯示裁切服務目前觀看視角，不影響施毒判定，也不要求每個生物各渲染一張畫面。
- 同時覆蓋即時觀察與回放的建立、消失、進出、暫停及跳轉。

### 觀察介面配置

- 頂部工具列與展開的右側面板各自保留空間，世界使用剩餘區域。
- 面板可收合；首次選取個體時展開，手動收合後換選個體仍保持收合，直到手動展開。偏好只保留於本次執行。
- 收合不取消選取或退出個體視角。回到全景且無詳細資料時釋放右側空間。
- 全景完整容納地圖；個體模式切換面板時保持相機中心與縮放尺度，正確更新點選與縮放的座標映射。
- 1280×720、960×540 均保留可操作的世界區域。面板隨視窗縮小、內容可捲動、工具列必要時換行，不退回覆蓋世界。
- UI 點擊不得穿透為世界選取；狀態與必要控制可達，文字精簡。

## Testing Decisions

- 使用者已確認的最高驗收入口是既有正式世界入口：固定配置、種子與指定動作驅動同一世界，從輸出觀察、事件、畫面及回放驗證。優先沿用此入口，不另建一套世界測試模型。
- 好的驗證檢查外部行為，例如察覺條件、記憶過期、避險選擇、畫面裁切及操作結果；不斷言私有函式呼叫次數或內部容器形狀。
- 共同世界觀察、規則控制器、觀察介面與回放經同一場景鏈驗證；學習觀察契約使用既有 bridge 入口核對，無需啟動訓練。
- 沿用既有幼體照顧及記憶推測驗收的先例：固定場景、可見與無畫面狀態對照、逐步紀錄、回放前後跳轉及成本摘要；不以既有短程結果推論本輪效果。
- 每個功能任務交付自己的場景證據、必要畫面與回放核對，不把全部測試或呈現延後到最後一張任務。最終任務負責跨功能整合與效能報告。
- 先前文件發佈只檢查內容、引用及依賴；本輪實作沿用正式世界及 bridge，新增的驗證服務下列外部行為。
### 驗收情境與量測

- 使用固定配置及指定動作驗證：遠處、背後、中心不可見而邊緣可見、相切、身在煙幕內、圓心、重疊煙幕、同種／異種、失去視野、5 秒到期、重新觀察消失。
- 用相同觀察資料核對規則與學習介面；驗證一般繞避、離開優先、緊急穿越、親代保護與過時記憶。
- 固定狀態或固定動作下對照修改前後的世界結果，區分規則行為變化與意外改動世界規則。
- 兩種驗收尺寸檢查面板開合、換選、全景、視窗調整、點選與縮放；即時與回放均檢查，回放前後跳轉不殘留未來資訊。
- 記錄固定配置、種子、生物數、煙幕數、模擬時間與量測方式；分別量測感知／避險與可見渲染成本，報告基準、差異及限制，不以推論次數宣稱整體效能改善。先量測，不預設加入複雜索引。
- 建置、既有相關檢查及必要的場景驗證皆完成後才結案；各任務記錄人工重現方式與結果，不只核對可啟動。
- 若資料格式變更，記錄舊回放可讀範圍與不支援情況，不為舊資料虛構過去的煙幕情報。
- 每次改動以繁體中文提交；全部驗收與結案後整份功能資料夾移至 archive、更新引用，將有效知識整合正式文件。


## Out of Scope

- 改變模擬步長、決策間隔、gamma 或啟動 PPO／混合控制訓練；每 0.2 秒決策維持後續構想。
- 改變煙幕施毒規則、傷害或其他技能效果，加入煙幕遮蔽生物視線。
- 果實、採集、攜帶、長期生態平衡及幼體照顧長期對照。
- 完整路徑搜尋、全域最佳避險、保證永遠不中毒，或在未量測前加入複雜空間索引。
- 讓生物讀取畫面辨識煙幕、共享個體情報，或直接取得未觀察的世界真值。
