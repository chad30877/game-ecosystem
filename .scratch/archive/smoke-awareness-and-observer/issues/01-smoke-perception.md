# 01：煙幕察覺、記憶與共同觀察

## What to build

讓觀看者能在選取個體後，於即時觀察與回放看見該個體的煙幕情報、可見／記憶狀態及情報年齡，並由共同觀察介面核對相同資訊。以圓與視野扇形相交察覺、完整範圍情報及 5 秒記憶完成整條流程；以[規格](../spec.md)為準。

## Blocked by

無

## Status

resolved

## 驗收條件

- [x] 不可見煙幕不洩漏；中心不可見而邊緣可見仍能察覺。
- [x] 可見、記憶、到期、重見消失均符合規格，不讀取視野外失效時間。
- [x] 規則與學習介面取得一致情報，欄位與版本相容性有紀錄。
- [x] 涵蓋圓心、相切、重疊與同種／異種場景，記錄人工重現方式。
- [x] 即時與回放的個體資訊可辨識可見／記憶及情報年齡，前後跳轉不帶入未來資料；本張不依賴煙幕圖形裁切或新版面才能驗證。
- [x] 新情報不揭露施放者或精確失效時間；舊回放未保存的情報不虛構補齊，相容範圍有紀錄。

## 討論紀錄

- 使用者已確認五項拆分與前置關係，正式發佈為 ready-for-agent；依使用者指示先不實作。
