# 02：規則煙幕避險

## What to build

讓觀看者能在固定情境中看到生物依已知煙幕繞避、離開或緊急穿越，並在即時觀察與回放核對簡短決策原因；僅依個體情報調整局部移動。以[規格](../spec.md)為準。

## Blocked by

01：煙幕察覺、記憶與共同觀察

## Status

resolved

## 驗收條件

- [x] 平時避開有害範圍，同種煙幕不一律迴避。
- [x] 離開優先於採食、餵養、培育、主動攻擊，保護不無條件進入煙幕。
- [x] 僅既有緊急逃命允許穿越，安全方向可行時優先使用。
- [x] 圓心、重疊、過時記憶與既有動作限制不造成無效行為，具固定場景證據。
- [x] 即時與回放可核對相同行為及決策原因；固定動作對照確認未改施毒與世界規則。

## 討論紀錄

- 使用者已確認五項拆分與前置關係，正式發佈為 ready-for-agent；依使用者指示先不實作。

## 完成紀錄

正式世界驗證繞避、離開優先、照顧／保護、重疊、過時情報、定身及緊急穿越。審查找出的緩衝帶與世界邊界問題經 boundary-red／green 驗證修正，Spec 複查剩餘 0 項。review-rules 的 651 影格可回放離開／繞避原因；650 步固定動作與起始提交世界狀態相同。人工重現及完整證據見 docs/smoke-awareness.md、artifacts/smoke-validation/。
