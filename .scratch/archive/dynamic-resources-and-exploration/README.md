## 依賴理由

- 01 完成後，02 與 03 可分別進行；03 以指定動作改變食物狀態，不需要等待自然更替。
- 04 需要 03 的方向觀察與資訊新鮮度；05 需要完整動態環境與掃視保障，避免以不同規則完成訓練。
- 06 要記錄並重現 05 的探索獎勵及完整新觀察；07 使用 06 的歷史證據，亦間接依賴前述所有切片。
- 沒有單列預先重構任務；必要的局部調整併入各可驗證切片。任務依賴不代表授權啟動平行 agent。
