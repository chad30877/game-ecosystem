## What to build

將日常模擬輸出改為來源資訊、每一模擬秒的群體時間序列與精簡結果摘要，讓 Codex／其他 LLM 可先讀摘要再追查時段，避免預設逐步保存完整世界。

需求依據：[正式規格](../spec.md) S03、S08；同時遵守 S01 的範圍與授權、S07 的證據保留及 S09 的交付要求。

## 驗收條件

- [x] 一般執行不輸出逐步個體狀態、完整快照或詳細 metrics；reset、加入／死亡及退出紀錄也不繞過輕量預設。
- [x] 樣本依模擬時間產生，保留輪次起訖與正常提前停止的最後摘要；暫停不產生牆鐘樣本，重建後統計不串錯世界。
- [x] 各物種人口、出生死亡、低飽食及飽食統計、來源數、三處果實存量與規格要求的累計流量可追溯；在抽樣間發生的事件不漏算或重複累加。
- [x] 精簡摘要呈現起訖、變化範圍、累計事件、停止原因及來源／時間序列入口；不從不完整來源補造未知結論，不自動呼叫 LLM。
- [x] 更新依賴舊完整 step 的必要摘要讀取邏輯，驗證固定短情境的已知人口與果實帳；摘要與時間序列在多輪及提前停止情境一致。
- [x] 同建置同配置同種子下，改用輕量模式不改變世界結果；完整錄製或詳細診斷僅在明確要求時另行開啟。

## 人工測試方式

一般啟動並暫停、重建、提前停止，查看簡短摘要與按模擬秒記錄的資料；核對沒有日常逐步個體大檔。這是後續驗收方向，本次未執行；實作後補入確切命令及結果。
