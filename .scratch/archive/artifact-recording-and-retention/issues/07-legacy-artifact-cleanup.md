## 驗收條件

- [x] 盤點當時實際存在的舊模擬紀錄、回放、統計、日誌、失敗檔與驗收素材，另列現行測試依賴及模型／工具／快取等排除項；不以副檔名或 artifacts 全樹推定全部可刪。
- [x] 缺乏建置識別的舊資料如實記錄，不猜造版本，也不將首次整理擴大成掃除專案外自訂輸出。
- [x] 現行測試固定素材已移至受維護且不會被日常淘汰的位置，或隨已退役測試取消依賴；新驗收不再要求 v9–v14 歷史代表檔。
- [x] 正式結果與需要繼續比較的資料已妥善整理，文件區分歷史證據路徑與目前仍存在的原始檔；不改寫 11 的既有驗收結論。
- [x] 實際刪除只按確認範圍內的分類目標執行，先核對解析後的絕對路徑與使用狀態；保留精簡處置結果、排除項及限制，不把文件發佈當作現在的清理授權。
- [x] 整理後核對現行必要測試／入口仍能讀到保留素材，環境、模型、快取與正式 Git 結果不受本輪清理影響；臨時大檔用完清除。
