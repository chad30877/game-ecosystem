## What to build

## 驗收條件

- [x] 最近五次以已停止執行排序且包含失敗場次，不將一個執行的多輪分段算成多次；仍執行中的資料不提前淘汰。
- [x] 另保留最近一次全批成功錄製的全部分段及必要摘要／來源資訊，即使其輕量資料已超過五次；其他舊錄製的大檔與其輕量保留規則分開處理。
- [x] 新錄製部分或全部失敗不替換上一份成功成品；失敗來源隨執行淘汰，成功來源僅在所有需保存資訊與分段檢查完成後移除。
- [x] 新建置成功採用後淘汰舊建置資料；建置失敗不清理。並行執行、封裝及播放期間使用中的檔案保持可用，結束後依政策處理。
- [x] 只刪專案內受管根目錄中有可靠歸屬的候選；測試越界、連結、未知資料、自訂輸出及非模擬檔案均不被誤刪。
- [x] 清理錯誤可辨識，重試不影響應保留資料；不新增常駐服務或永久釘選功能。
- [x] 以隔離的測試產物完成五次／一次、跨建置、並行使用、失敗及範圍檢查；本任務不清理尚未分類的真實舊 artifacts。

## 人工測試方式

產生超過五次執行、兩次成功錄製及一次失敗錄製，查看留下的資料；保持一段播放中再觸發清理，核對播放檔未消失。這是後續驗收方向，本次未執行；實作後補入確切命令及結果。
