# 左側世界與大型預設視窗

狀態：resolved。

使用者要求世界固定在左側，右側保留展開資料的空間，並統一以大尺寸啟動。此要求取代先前收合面板時擴張世界區域的配置。

- 全景、選取個體、面板開合均保留相同右側空間；開合不移動世界或改變縮放。
- 空白資料區不殘留面板文字，世界記憶標記不越界。
- Player、即時觀察、回放及 Python／訓練入口預設 1280×720；仍允許使用者明確指定尺寸或手動調整。
- 不變更模擬、觀察或模型資料契約，不執行訓練。

驗收：建置、Python 型別及語法檢查；實際核對即時／回放的預設尺寸、面板開合與返回全景；bridge 核對入口覆寫設定。
