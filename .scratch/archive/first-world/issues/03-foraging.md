# 03：可觀看的覓食與飢餓循環

**Status:** resolved

**What to build:** 在有邊界的 2D 地圖觀看三物種移動與採食，並看見食物再生、能量變化及飢餓死亡。

**Blocked by:** 01：工具鏈與最小訓練往返。

## 驗收條件

- [x] 以規則控制器展示三物種各約 10 隻、4 處產地與零散食物；清楚標示尚非學習結果。
- [x] 接近並採食才取得能量，食物不可攜帶；自然再生不突破容量。
- [x] 活動消耗能量，能量耗盡造成健康損失直至死亡；可查看個體健康與能量以核對結果。
- [x] 畫面與無畫面共用世界規則；初始配置及種子可記錄並再次載入。

## 驗證方式

沿用規格提出的世界執行入口，核對可觀察結果並提供人工操作步驟；保留及執行屆時存在的有效測試。本任務不授權新增測試檔，若需要新增須先取得使用者同意。
