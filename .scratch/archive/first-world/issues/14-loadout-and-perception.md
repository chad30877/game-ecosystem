# 14: 個體技能配置與視野決策

> 2026-10-23 保存狀態更新：本文 artifacts 路徑保留為歷史驗證來源；大型原始紀錄與舊模型已淘汰，摘要及指定短回放的保存範圍見[產物清理紀錄](../../../../docs/artifact-retention.md)。歷史操作範例須改用仍存在或新產生的來源。

**What to build:** 個體出生時取得固定技能配置，並能依視野內資訊觀察環境、轉向及嘗試使用所攜帶的技能。

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] 三物種各有四招技能池；個體出生時等機率取得其中兩招，技能欄位身分固定至個體死亡，不因學習改變配置。
- [x] 初始及訓練族群盡量均勻涵蓋每物種六種配置；後代獨立抽取，不遺傳親代配置。
- [x] 世界提供共用能量、各技能獨立冷卻與同時最多施放一招的規則；無效施放不扣能量、不啟動冷卻、不自動改選。
- [x] 個體有獨立朝向；視野為 120° 扇形、距離沿用 observationRadius、不處理遮擋；策略可左轉／不轉／右轉，轉向上限每秒 180°，移動不改變朝向。
- [x] 策略可觀察視野內所有敵我個體的物種、位置與移動狀態，不設固定數量上限、不提供穩定追蹤識別碼；敵方離開視野後僅保留物種與最後位置 5 秒警戒，不沿用移動資訊，友軍不保留。
- [x] 沿用世界執行入口，以固定配置、種子及動作核對外部狀態與事件；保留並執行有效既有測試，不新增測試檔。

## 完成紀錄

- 2026-10-21：接續已 claimed 的部分修改，完成出生固定兩招、六種組合均衡起始族群、後代獨立抽取、共用能量與獨立冷卻；無效施放不換招、不扣成本，施放中拒絕另一技能。
- 接入獨立朝向、120° 視野、每秒 180° 轉向與逐個敵人的五秒警戒記憶；友軍不保留、記憶不帶舊速度，策略不取得穩定個體識別。完整觀察不截斷，曾以二十九個同時可見個體核對。
