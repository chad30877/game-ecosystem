# 12：學習成效對照與第一版驗收

**Status:** resolved

**What to build:** 使用者取得可重複執行的對照報告與回放，判斷三物種策略及不同個體技能配置是否形成有效生存策略。

**Blocked by:** 09：重建、全新實驗與關閉後續訓；11：指定場次記錄與互動回放。

## 驗收條件

- [x] 固定初始策略、固定規則基準與訓練後策略在相同配置及 10 組固定起始種子比較，評估時停用策略更新。
- [x] 固定其他條件逐物種檢查，再補充三物種共同演化觀察；報告保存模型版本、技能配置、種子、規則及參數。
- [x] 報告包含各物種平均壽命、繁殖、族群曲線、滅絕頻率、上限觸發、未完成生命週期樣本及變異；依配置呈現結果，不以單一勝率或單次優勢宣稱有效。
- [x] 同物種各配置第一版共用策略；只有在樣本充足、相近情境與多次獨立訓練顯示特定配置持續落後，且獨立策略在相同情境穩定改善後，才提出拆分策略依據，不要求本任務直接拆分。
- [x] 以實測吞吐量、記憶體與磁碟使用估算訓練預算；串行人工驗收觀察、技能、重建、續訓與回放。
- [x] 若無可靠改善，標記學習效果未驗證並記錄原因與下一個具體實驗；不得以原型能啟動代替學習成效驗收。

## 驗證方式

沿用世界執行入口執行固定種子與配置的外部行為比較，人工核對報告與對應回放；保留並執行有效既有測試，不新增測試檔。

## 完成紀錄

2026-10-22：完成固定模型九條件、十種子共90場；逐物種控制比較及共同切換比較皆保存結果、變異、逐配置指標、未完成生命樣本與族群曲線。HTML離線報告實際核對條件切換及配置表，三場代表回放完整驗證，來源checkpoint不變。

串行人工核對可見觀察與技能、暫停、重建、保存結束及再次續訓，並核對回放倒轉的個體存在區間。真實Windows程序量測補足trainer／Unity峰值、吞吐量及磁碟預算；舊Mono零值不視為有效量測。結論為學習效果未驗證，維持同種共用策略，下一個實驗為精確零步祖先與至少三次獨立十萬步訓練。

最終Standards硬違規0、待修異味0；Spec待修0。Unity建置、既有bridge、compileall、Pyright、相依與PowerShell解析通過，未新增測試檔。方法、實測、限制與證據路徑見 docs/evaluation.md、docs/replay.md。
