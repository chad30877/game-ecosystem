# 04：繁殖、衰老與世界結束

**Status:** resolved

**What to build:** 觀察生物成年、繁殖與老死，並在滅絕或時間上限後取得一輪完整結果。

**Blocked by:** 03：可觀看的覓食與飢餓循環。

## 驗收條件

- [x] 達成年齡、能量及冷卻門檻才自動繁殖，成功出生消耗親代能量；後代需完成成長期。
- [x] 人口上限僅阻止新增出生，不刪除個體或扣除失敗繁殖成本；記錄上限觸發。
- [x] 可觀察年齡、出生與死亡；壽命耗盡死亡，統計保留死亡原因及尚未完成生命週期個體。
- [x] 單物種滅絕不提前結束；全體死亡或時間到達時輸出結束原因並可重建世界。

## 驗證方式

沿用規格提出的世界執行入口，核對可觀察結果並提供人工操作步驟；保留及執行屆時存在的有效測試。本任務不授權新增測試檔，若需要新增須先取得使用者同意。
