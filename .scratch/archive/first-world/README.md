## 執行方式

由 01 開始；完成後 02 與 03 可分別進行。05 完成後 06、07 可分別進行；14 可先行，15–17 依賴 14；08 依賴完整戰鬥與技能任務，10 依賴 04 及技能任務。此排序表示任務依賴，不代表已授權另外建立聊天或啟動平行 agent。

人工核對：開啟規格及逐張任務，確認依賴、驗收條件與狀態。任務完成需附外部行為驗證結果；新增測試檔仍需使用者另行同意。
