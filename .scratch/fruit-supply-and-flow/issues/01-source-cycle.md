# 01 逐顆果實與來源生命週期

## Status

ready-for-agent

## What to build

將連續食物產出改成有識別、成熟時刻與保存狀態的逐顆果實，建立首次成長、結果、等待腐爛期限、休養及來源到期的完整生命週期。先提供自然進度與可套用有界培育倍率的介面。

需求依據：[正式規格](../spec.md) S02、S09.1–3、S09.10。同時遵守規格 S08 的範圍與變更邊界。

## Blocked by

無前置任務；仍須取得後續實作授權。

## 驗收條件

- [ ] 大小型每輪分別等機會抽 2–4／5–7 顆，容量 4／7；每輪只抽一次，採走或腐爛不補名額。
- [ ] 自然週期符合首次等待 10／15、結果 30／40、休養 20／30、壽命 120／240 秒；每輪成熟非線性、可重現，最後一顆在結果期終點。
- [ ] 成熟後保存四十秒、最後十秒將腐爛；未採或已採的相同果實不因來源進度改變期限。
- [ ] 提前採光仍等待本輪最後腐爛期限；來源到期只移除未採果實，已採果實繼續自身期限。
- [ ] 固定情境涵蓋零果等待、採光、不採、來源先到期與中途取走；產果、腐爛、到期損失及存量可核對守恆。
