## 驗收條件

- [x] 培育範圍 1.5、有效時間每秒六魔力，無啟動費或額外冷卻；不可負魔力或免費加速，普通回魔與營養恢復不改。
- [x] 倍率 1＋成長倍率、最多兩倍，階段最短自然時間一半、成熟間隔至少一秒；同來源取最強而不疊加。
- [x] 只加速首次成長、結果進度與休養，不加果數、不延壽、不加速果實老化；停止／離場／失效不留尾效，來源進度保留。
- [x] 施法需有效可見來源、距離與行動互斥；無來源或等待腐爛期限時不可空耗培育。
- [x] 播種費十二、冷卻八秒、距離三，合法類型內小八大二；失敗不付費不冷卻、不揭露隱藏阻擋，成功不得撤銷重抽。
- [x] 固定情境涵蓋出生／成年強度、多個施法者、交接、資源不足、空間只容小型／已滿及來源到期；世界規則不依 AI 可能保守而放寬產能上限。

## 完成紀錄

- 2026-10-30：新增 `ProductionRules`，世界在實際位移、戰鬥及控制效果後判定施法者，再推進來源，最後結算食物操作；因此位移超距或已死亡者不能留下免費效果，果實到期仍先於任何食物操作完成。
- 培育按有效時間每秒六魔力，無啟動費與冷卻；部分魔力只支付可負擔時間，其餘自然推進。來源末果成熟轉等待、來源到期等半步邊界只收實際有效時間費用。首次成長、結果與休養共用原有進度，相鄰成熟與倍率上限仍由 `FruitRules` 約束，保存與壽命不加速。
- 同來源按成長強度、開始時刻、可重現同時抽選依序選有效者；沒有所有權或遠端預約，採集不受阻擋。既有目標有效時保持；`WorldAction.productionSource` 是可選的明確來源識別，零表示維持有效舊目標或選最近可見有益來源，失效明確目標不偷偷替換。煙幕避險重建動作會轉傳此欄。
- 播種使用共同 `SourcePlacementRules`，點位先驗證可見、距離與完整生長圓，再按合法類型八二抽選；不額外用生物或陷阱占地阻擋。成功從步末時間建立零歲、零果來源，魔力十二、冷卻八秒；失敗不扣費、不冷卻，也不輸出隱藏阻擋原因。
- `CombatConfig.cultivateMana` 現為每秒費用（初值六），舊持續時間／冷卻欄位保留讀取但不控制新規則；舊 `SkillRules` 的加法培育、固定小型播種與培育時間阻擋其他技能已移除。普通回魔與營養恢復結算未變。
