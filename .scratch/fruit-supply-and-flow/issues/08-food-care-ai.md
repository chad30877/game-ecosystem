## 驗收條件

- [x] 一般飽食 ≤65 吃一顆重判，≤45 自救優先；安全時偏向裝滿，急事不為補滿延誤。
- [x] 幼體 ≤40 且無果啟動照顧至 ≥60／成年／失效；親代 ≥50 開始、≤45 中止，自用不固定保留一顆。
- [x] 只主動送自己的幼體；候選與最低飽食相差十內選較近者，已開始有效交付維持；未知持果不當零。
- [x] 自用較舊、交付較新，估計取得／負重走路／交付／進食時間，不讀到期真值、不加兩秒緩衝，危急無替代可冒險。
- [x] 成幼體無果、有需求且安全才接收，保留有效行動；相近邀請親代優先、再距離、再公平抽選。
- [x] 安全空檔逐顆放到一顆、較舊優先且每顆重判，近身先逃、不回頭補滿；換果有明確用途，不囤地、不放下撿回循環。
- [x] 固定情境涵蓋有果幼體先吃、拒絕交付、威脅介入、記憶失聯；自動繁殖與既有親代保護保留，新生無果、舊飽食轉移旁路已移除。

## 完成紀錄

- 2026-10-30：完成 `FoodCareController`，接入原 `ForagingController` 的避險、爭食與護子優先序，將舊直接餵養／連續採食決策改為明確 `FoodAction`。AI 只讀自身、可見及記憶 DTO，沒有查詢世界果實精確期限、隱藏來源／持果或遠處個體真值。
- 優先序：原撤退、近期受擊及親代保護先處理；自身飽食 ≤45 自救，已開始進食維持整顆；合格照顧先於一般 ≤65 自用，因此親代 50–65 仍能開始送果。新交付要求 ≥50，有效交付可在 45–50 續行，≤45 改自救並由世界解除配對。`foodCareChildren` 保留幼體需求從 ≤40 啟動、至 ≥60／成年／確認失效停止的遲滯；未知持果不當零顆，親子失聯搜尋與已搜尋位置仍保留。
- 自用選估計吃得完的較舊果實，送果選估計可完成負重走路、交付及進食的較新鮮果實；`WalkSeconds` 使用三物種走速、當前負重及自身控制狀態，不預設奔跑。取得另加採集一秒／拾取半秒，交付與進食只加實際一秒＋兩秒，沒有額外兩秒緩衝。危急且沒有可行替代時可吃／接收高風險果實。
- 接收者先保留有效採集、拾取、進食或交付，空手、有需要且安全時才選當前可見邀請；可行近處邀請先於新遠處補貨，親代優先、再近者、同條件以 `World.Seed`、個體與步數作可重現抽選。此抽選不消耗生產、施法或世界爭果亂數；新 `Seed` 為唯讀屬性。
- 安全時補滿成體三格／幼體一格；食物與送果急事先處理。逃生近身先移動，有安全空檔才逐顆放較舊果至一顆，每顆完成後重判；`foodUnloading/foodAvoidRefillUntil` 與最多十六筆 `foodDiscarded` 防止立即補滿／撿回。丟棄記憶只用自身決策時間，四十秒後淘汰，不讀真實期限。一般換果僅在滿載舊果估計送不到、可見新果確實可完成照顧路程時先騰一格，不建立地面囤貨。
- 已知威脅同時檢查自身與送果幼體位置；原護子不接戰的情境不會改由送果走進已知危險。新競爭資料使用可見採集／拾取互動與可見來源位置，沒有把攜帶進食位置誤當原來源。
