- [x] 以半徑八內可見／記憶來源評估，先取可用果；已有未成熟／結果／休養來源先利用、培育或探索，幼株計入且舊情報先確認。
- [x] 沒有可持續產出的已知來源或只剩等待期限來源才考慮播種；滿載無送果需求不播，魔力 ≥40、可等待時飽食 ≥30，急事仍優先。
- [x] 在可見施放範圍依已知占地、邊界與危險選安全候選，先選點再抽合法類型，不為拿大型撤銷／重抽。
- [x] 失敗至少隔一秒，無候選就移動掃視探索；不得每步繞過間隔、同無效點原地循環或藉失敗定位隱藏來源。
- [x] 培育取消五十／二十五門檻，有收益且付得起才開始／繼續；可見較近有益目標優先，開始後不因稍近的新株切換。
- [x] 同強度先開始者續留、同時公平抽選，較強可接手；只用可見資訊協調，不遠端預約，不雙停雙開；允許短暫觀察延遲。
- [x] 固定情境涵蓋全部成熟等待、休養空株、缺施法技能、低魔力、飢餓、交付與危險插入；記錄選擇與停止原因。

- 有效培育不受無關陳舊來源的回訪打斷；急需吃、交付、撤退與護子仍先行。任何正魔力均可開始支付可負擔的有效時間，沒有五十／二十五門檻或六魔力啟動費。
- 播種候選使用三層、各十三個視線角度的有限安全點；半徑取施放距離與觀察半徑的較小者，再以純幾何視線、世界邊界、已知生長圓與已觀察威脅／煙幕排除。種子、個體與步數只用於獨立的候選點抽選，不消耗世界生產亂數；類型仍由世界在選定合法點後八二抽選。無候選時探索，若探索暫無移動則主動掃視。
- 新播種要求魔力至少四十、飽食至少三十；等待估計採兩型首次成熟時間的較長者，加負重走路、採集一秒及進食兩秒，並核對自身基礎／已啟用營養消耗與剩餘壽命，不讀既有來源精確進度。滿載又無已知照顧需求不播；滿載但舊果無法送達且有已知需求仍可考慮未來供給，不直接額外給果。
