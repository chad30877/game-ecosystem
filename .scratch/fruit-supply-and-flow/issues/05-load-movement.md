## 驗收條件

- [x] 零／一／二／三顆速度倍率為 1／1／0.9／0.8，三物種一致，幼體一格不受罰。
- [x] 正在吃及未送完果實仍算重量，接收預留尚未到手不算；移出或腐爛後更新。
- [x] 普通走跑與原減速相乘，定身仍零；負重只套一次，不隨時間累加。
- [x] 衝鋒／疾行固定持續時間下速度及距離受負重，傷害、費用與時間不變；不擴張原減速或敵方推拉規則。
- [x] 不新增負重資源消耗，不拖慢食物操作與培育；固定場景比較不同果數、減速、定身與技能位移。
