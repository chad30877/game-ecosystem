## 驗收條件

- [x] 可見來源四階段、現有果數、粗略新鮮度、持果及暫占／交付／培育互動可辨；不暴露精確進度、到期、未來果數或隱藏意圖。
- [x] 自身持果的新鮮度決策也使用粗略資訊；視野外果實被拿走／腐爛／互動結束不直接刷新記憶。
- [x] 來源最多三十二筆，三十秒為陳舊尺度；地面果實十六筆、離視野十秒，其他個體持果／互動五秒後未知而非零顆。
- [x] 回訪證偽清除，舊來源記憶僅作回訪線索，不推斷連續回滿；重新觀察修正，避免重追同一落空果實。
- [x] 親子關係、已搜尋失聯位置及重新觀察規則保留，不新增幼體視野外追親代。
- [x] 固定情境用相同觀察但不同隱藏世界核對資訊隔離，並驗證視野／煙幕、掃視、過時與記憶容量邊界。

## 完成紀錄

- 2026-10-30：完成 `FruitPerception`，由 `World.RefreshPerception` 投影可見真值為粗略資料；來源四階段、生長類型、目前果數及逐顆新鮮度可辨，不投影來源年齡、生命倒數、未來額度或排程。採集者可見但果實在視野外時，只提供動作類型，不揭露果實識別、來源或座標；暫占者識別同樣受可見性限制。
- 08／09 接點：`IndividualState.ownFruits`、`groundFruitMemory`、`FoodMemory.fruits/growthType/phase/stale`；單顆 `FruitObservation` 提供 `fruit/source/holder`、粗略 `freshness`、最後觀察及觀察區間。`EstimateRemaining(time)` 僅由粗略新鮮度及觀察時間估算；首次新鮮觀察的剩餘區間為 10–40 秒，將腐爛為 0–10 秒，重見只收窄原區間，不重新給四十秒；實際選果與路程評估由 08 接續。
- 新鮮度區間跨來源、攜帶、地面及邀請保留。`fruitFreshnessMemory` 最多 1024 筆，只存識別與粗略觀察時間／類別，不存位置、持有者或追尋依據，超過觀察上界或容量時淘汰；邀請暫停再出現及地面追尋期限失效後重見，不會以同顆已知果實重新保鮮。保存上界是過去觀察所得區間，並非精確世界期限。
- `foodInteractions` 最多 256 筆，提供可見個體的持果數、當前食物操作、可見目標、邀請／粗略邀請果實與可見培育來源、強度、首次觀察順序。`EntityObservation.food` 及 `FamilyMemory.food` 使用同一筆觀察；離視野五秒後移除互動觀察、親子 `food=null` 表示未知，原值改為 -1，不當零顆。親子關係、已搜尋失聯位置與既有重見更新保留；08 不可使用互動的最後觀察位置新增幼體視野外追親代行為。
- 來源記憶最多三十二筆，三十秒只標陳舊，永不推斷自動回滿；地面最多十六筆，離視野十秒失去追尋線索。視野外拿取、腐爛、互動結束或死亡不刷新最後觀察；回訪空位置才清除。`fruitKnowledgeAvailable` 區分新規則已提供的情報與舊回放未提供資訊。
- 共同觀察維持十九維自身向量與十維可變列；來源列 0 現含可見、觀察年齡、四階段、果數、陳舊與類型；新增 -6 自身果實、-7 地面果實、-8 個體食物互動、-9 來源逐顆果實。這些列不輸入果實／個體追蹤識別，不含精確期限或未來果數。`WorldRunner` 張量容量另保留 `32×max(兩型果數上限)+16+3+256` 列，欄寬仍十；規則／模型版本由 11 統一更新，不宣稱舊模型可用新語意。
