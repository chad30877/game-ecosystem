## 驗收條件

- [ ] 可見來源四階段、現有果數、粗略新鮮度、持果及暫占／交付／培育互動可辨；不暴露精確進度、到期、未來果數或隱藏意圖。
- [ ] 自身持果的新鮮度決策也使用粗略資訊；視野外果實被拿走／腐爛／互動結束不直接刷新記憶。
- [ ] 來源最多三十二筆，三十秒為陳舊尺度；地面果實十六筆、離視野十秒，其他個體持果／互動五秒後未知而非零顆。
- [ ] 回訪證偽清除，舊來源記憶僅作回訪線索，不推斷連續回滿；重新觀察修正，避免重追同一落空果實。
- [ ] 親子關係、已搜尋失聯位置及重新觀察規則保留，不新增幼體視野外追親代。
- [ ] 固定情境用相同觀察但不同隱藏世界核對資訊隔離，並驗證視野／煙幕、掃視、過時與記憶容量邊界。
