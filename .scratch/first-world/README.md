# 第一版可學習生態世界任務索引

[正式規格](spec.md)已確認並發佈，原始 12 張功能任務各自維護狀態與驗收條件，初始標記 ready-for-agent；下表另列後續追加的環境維護任務。僅在前置任務全部 resolved 後開始執行。

| 編號 | 任務 | 前置任務 | 交付行為 |
| --- | --- | --- | --- |
| 01 | [工具鏈與最小訓練往返](issues/01-toolchain.md) | 無 | 從本機啟動最小可見場景，讓 Python 取得局部觀察、回傳移動動作，並能無畫面執行相同場景。 |
| 02 | [三物種共享策略與動態個體驗證](issues/02-shared-policies.md) | 01 | 在最小場景中讓三種策略各自控制多個同類個體，並在訓練期間加入、移除個體及保存恢復訓練。 |
| 03 | [可觀看的覓食與飢餓循環](issues/03-foraging.md) | 01 | 在有邊界的 2D 地圖觀看三物種移動與採食，並看見食物再生、能量變化及飢餓死亡。 |
| 04 | [繁殖、衰老與世界結束](issues/04-life-cycle.md) | 03 | 觀察生物成年、繁殖與老死，並在滅絕或時間上限後取得一輪完整結果。 |
| 05 | [炎角獸近戰與烈焰衝鋒](issues/05-flame-charge.md) | 04 | 在覓食世界中觀看炎角獸攻擊異種、施放衝鋒並付出能量與冷卻代價。 |
| 06 | [霜羽獸遠程牽制與近戰對抗](issues/06-frost-combat.md) | 05 | 觀看霜羽獸冰箭攻擊炎角獸，重現遠程拉扯與近戰接敵窗口。 |
| 07 | [苔靈培育與護盾生存](issues/07-moss-defense.md) | 05 | 觀看苔靈在食物附近培育並以護盾抵抗攻擊，展示第三種生存方式。 |
| 08 | [三物種戰術學習與連續訓練](issues/08-tactical-learning.md) | 02、06、07 | 讓三物種在完整世界依局部感知學習戰術動作，並在每輪結束後保留策略繼續。 |
| 09 | [重建、全新實驗與關閉後續訓](issues/09-resume-training.md) | 08 | 使用者可保留策略重建世界、清除策略建立新實驗，並在關閉程式後繼續已保存的訓練。 |
| 10 | [即時觀察與個體檢視](issues/10-observation.md) | 04 | 使用者能暫停、調速、縮放鏡頭與查看任一生物，理解當前世界狀態。 |
| 11 | [指定場次記錄與互動回放](issues/11-replay.md) | 08、10 | 記錄一場完整三物種互動，之後以時間拖動、暫停、調速及個體檢視分析歷史。 |
| 12 | [學習成效對照與第一版驗收](issues/12-evaluation.md) | 09、11 | 使用者取得可重複執行的對照報告與回放，判斷三物種是否學到有效生存策略。 |
| 13 | [專案內環境與輸出遷移](issues/13-project-environment.md) | 無 | 後續追加的環境維護：將工具、套件與活躍輸出改由專案目錄管理。 |

## 執行方式

由 01 開始；完成後 02 與 03 可分別進行。05 完成後 06、07 可分別進行；10 只依賴 04。此排序表示任務依賴，不代表已授權另外建立聊天或啟動平行 agent。

人工核對：開啟規格及逐張任務，確認依賴、驗收條件與狀態。任務完成需附外部行為驗證結果；新增測試檔仍需使用者另行同意。
