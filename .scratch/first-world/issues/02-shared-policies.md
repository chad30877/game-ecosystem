# 02：三物種共享策略與動態個體驗證

**Status:** ready-for-agent

**What to build:** 在最小場景中讓三種策略各自控制多個同類個體，並在訓練期間加入、移除個體及保存恢復訓練。

**Blocked by:** 01：工具鏈與最小訓練往返。

## 驗收條件

- [ ] 三物種策略分離，同種個體參數共享；記錄實際連線與更新證據。
- [ ] 透過可操作的加入／移除事件驗證個體出生死亡的訓練介面；移除一隻不會重設同種策略，個體識別不混用。
- [ ] 小規模實驗可保存後重新啟動並接續訓練；此處僅驗證工具能力，不代替完整產品續訓操作。
- [ ] 驗證報告列出無畫面、動態個體及恢復支援的結果與限制；若未通過，後續正式學習實作保持被阻擋。

## 驗證方式

沿用規格提出的世界執行入口，核對可觀察結果並提供人工操作步驟；保留及執行屆時存在的有效測試。本任務不授權新增測試檔，若需要新增須先取得使用者同意。
