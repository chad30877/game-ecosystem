# 07：苔靈培育與護盾生存

**Status:** resolved

**What to build:** 觀看苔靈在食物附近培育並以護盾抵抗攻擊，展示第三種生存方式。

**Blocked by:** 05：炎角獸近戰與烈焰衝鋒。

## 驗收條件

- [x] 苔靈沒有傷害技能，控制器可選擇培育或護盾；技能有可見狀態、能量消耗及冷卻。
- [x] 培育加速食物再生但不突破容量，不能無成本無限增生；苔靈滅絕後食物仍會自然再生。
- [x] 護盾效果可從所受傷害及事件核對，炎角獸可作為驗證攻擊來源，不依賴遠程技能完成。
- [x] 在世界循環中演示苔靈採食、使用技能及生存／死亡，確認不繞過生命與資源規則。

## 驗證方式

沿用規格提出的世界執行入口，核對可觀察結果並提供人工操作步驟；保留及執行屆時存在的有效測試。本任務不授權新增測試檔，若需要新增須先取得使用者同意。

## 完成紀錄

- 2026-10-20：前置 05 已 resolved，完成無傷害的培育與護盾、耗能及共用冷卻。培育受範圍、持續時間、存活及容量限制；護盾減免戰鬥傷害但不抵銷飢餓或老死。
- Unity 編譯及建置通過；固定動作驗證苔靈採食與出生、培育到容量停止、護盾近戰傷害由 12 降為 4.2，護盾結束恢復原傷害。唯一苔靈被炎角近戰擊殺後，食物仍自然再生。
- 未新增測試檔；參數、證據及人工操作見 [三物種技能驗證](../../../docs/combat.md)。
