# 11：指定場次記錄與互動回放

**Status:** ready-for-agent

**What to build:** 記錄指定場次中的世界狀態及技能事件，之後以時間拖動、暫停、調速及個體檢視分析歷史。

**Blocked by:** 08：三物種戰術學習與連續訓練；10：即時觀察與個體檢視。

## 驗收條件

- [ ] 可指定評估場次記錄狀態及出生、死亡、技能施放、技能命中／效果與資源變化等事件；固定評估模型時不更新策略。
- [ ] 回放由記錄還原，不重新執行模型推測原場次；可向前及向後拖動時間。
- [ ] 回放時個體狀態、存在區間、技能配置與效果事件對應原場次；暫停與拖動不改變模型或原始資料。
- [ ] 只記錄指定場次並顯示／記錄檔案容量；缺漏或不相容記錄有明確錯誤。

## 驗證方式

沿用世界執行入口比對記錄場次與回放中的外部狀態及事件；人工核對時間拖動、暫停與調速。保留並執行有效既有測試，不新增測試檔。
