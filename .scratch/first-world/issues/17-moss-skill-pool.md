# 17: 苔靈技能池與生態／區域控制

**What to build:** 苔靈以培育、播種與控制技能支援族群，不取得直接傷害能力。

**Blocked by:** 14：個體技能配置與視野決策。

**Status:** resolved

- [x] 苔靈技能池包含培育、播種、根鬚纏繞、孢子煙幕；沒有直接傷害技能，技能選擇遵循共用能量與獨立冷卻規則。
- [x] 培育加速既有食物再生，不直接創造食物；播種只在範圍內、未占用、可行走且未達資源上限的位置成功，失敗不耗能、不進冷卻，成功後食物延遲成熟且成熟前不可採食。
- [x] 根鬚纏繞為短距離範圍定身，不造成傷害，對苔靈無效且不由友軍觸發。
- [x] 孢子煙幕只影響敵方，不影響苔靈群體；造成不完全接管的微弱隨機方向移動偏向，固定週期換向且受轉向速度限制，不降低攻擊力。
- [x] 煙幕內按固定間隔施加中毒；離開後停止新增層數但既有中毒持續至逾時或刷新，最多五層，第五層再次施毒刷新時間且五層傷害加倍；重疊煙幕共用層數上限，不在同一毒傷間隔重複加層。
- [x] 控制與非控制持續效果按正式規格刷新／疊加規則運作；沿用世界執行入口及人工操作核對，不新增測試檔。
