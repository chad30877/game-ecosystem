# 14: 個體技能配置與視野決策

**What to build:** 個體出生時取得固定技能配置，並能依視野內資訊觀察環境、轉向及嘗試使用所攜帶的技能。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 三物種各有四招技能池；個體出生時等機率取得其中兩招，技能欄位身分固定至個體死亡，不因學習改變配置。
- [ ] 初始及訓練族群盡量均勻涵蓋每物種六種配置；後代獨立抽取，不遺傳親代配置。
- [ ] 世界提供共用能量、各技能獨立冷卻與同時最多施放一招的規則；無效施放不扣能量、不啟動冷卻、不自動改選。
- [ ] 個體有獨立朝向；視野為 120° 扇形、距離沿用 observationRadius、不處理遮擋；策略可左轉／不轉／右轉，轉向上限每秒 180°，移動不改變朝向。
- [ ] 策略可觀察視野內所有敵我個體的物種、位置與移動狀態，不設固定數量上限、不提供穩定追蹤識別碼；敵方離開視野後僅保留物種與最後位置 5 秒警戒，不沿用移動資訊，友軍不保留。
- [ ] 沿用世界執行入口，以固定配置、種子及動作核對外部狀態與事件；保留並執行有效既有測試，不新增測試檔。
