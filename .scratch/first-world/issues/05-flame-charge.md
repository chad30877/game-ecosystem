# 05：炎角獸近戰與烈焰衝鋒

**Status:** ready-for-agent

**What to build:** 在覓食世界中觀看炎角獸攻擊異種、施放衝鋒並付出能量與冷卻代價。

**Blocked by:** 04：繁殖、衰老與世界結束。

## 驗收條件

- [ ] 近戰與衝鋒命中可見且反映在健康、能量及事件；同種不受傷害。
- [ ] 衝鋒有距離與冷卻限制，衝鋒期間不受減速影響；不得無成本連續使用。
- [ ] 受傷可造成死亡；能量充足且脫離戰鬥後可緩慢恢復健康。
- [ ] 以可指定動作或規則控制器重現接敵場景，驗證碰撞與傷害；追擊與撤退不寫成強制學習結果。

## 驗證方式

沿用規格提出的世界執行入口，核對可觀察結果並提供人工操作步驟；保留及執行屆時存在的有效測試。本任務不授權新增測試檔，若需要新增須先取得使用者同意。
