**What to build:** 霜羽獸使用固定基本遠程攻擊及個體攜帶技能，能在輸出、牽制、位移與陷阱之間選擇。

**Blocked by:** 14：個體技能配置與視野決策。

**Status:** resolved

- [x] 技能池包含霜縛箭、穿透冰矢、寒霧遁行、冰霜陷阱；基本遠程攻擊不占技能名額且不自帶減速。
- [x] 投射物依實際碰撞判定命中，瞄準位置由策略輸出且可用於預判，不鎖定目標；自身中心效果不讀取瞄準點。

- [x] 控制同一效果重複施加只刷新時間、不疊強度；不同控制可並存，定身期間不累積新的移動偏向。
- [x] 技能結果由世界狀態及事件呈現，可見與無畫面執行一致；沿用世界執行入口及人工操作核對，不新增測試檔。
