# 01：工具鏈與最小訓練往返

**Status:** resolved

**What to build:** 從本機啟動最小可見場景，讓 Python 取得局部觀察、回傳移動動作，並能無畫面執行相同場景。

**Blocked by:** 無，可立即開始。

## 驗收條件

- [x] 核對 SSD 空間與工具相容版本，採用已確認的雙 SSD 配置：C 槽工具與活躍輸出、D 槽專案及獨立下載／歷史目錄；記錄實際安裝與執行位置。
- [x] 最小個體可在畫面依控制器動作移動，Python 可完成一次實際訓練更新；不得只以套件可匯入當作成功。
- [x] 同一場景可無畫面執行並輸出狀態、事件及步數；記錄版本、啟動方法、CPU／GPU 實際使用情況與初步吞吐量。
- [x] 建立可供後續沿用的世界執行入口；不加入完整生態、回放或美術。遇登入／授權限制明確回報，不宣稱驗證通過。

## 驗證方式

沿用規格提出的世界執行入口，核對可觀察結果並提供人工操作步驟；保留及執行屆時存在的有效測試。本任務不授權新增測試檔，若需要新增須先取得使用者同意。

## 討論紀錄

- 2026-10-20：使用者確認採用目前雙 SSD 配置，取代原 HDD 要求；Unity Hub 已安裝，Editor 已取得授權，接續建置與實測。

- 2026-10-19：開始實作，沒有前置任務。磁碟實測發現 C、D 均為 NVMe SSD，保留 D 槽唯一活躍專案，C 槽安裝工具與 Python 環境。未發現 HDD，不能宣稱完成實體 HDD 配置。
- 2026-10-19：Editor 已安裝，但建置遇到缺少登入 token 與授權的阻擋；需由使用者在 Unity Hub 登入啟用。自動安裝 Hub 被核准審查拒絕。保持 claimed，後續任務仍不得開始。

## 完成紀錄

- 已建立世界規則與控制器分離的最小來源、局部觀察／移動介面、可見及無畫面共用入口、JSONL 狀態與事件紀錄、Python 往返執行器、PPO 配置與相依鎖定。
- Python 語法、型別與套件相依檢查通過；無既有測試套件，未新增測試檔。
- 2026-10-20：Unity 建置通過；修正無效套件宣告與關閉前額外步進影響驗證計數的問題。可見與無畫面均完成 512 步，狀態／事件逐筆一致；無畫面約 934 步／秒，可見約 50 步／秒。

- 執行結果已封存至 D 槽歷史目錄。版本、位置、實測證據及限制見 [工具鏈驗證紀錄](../../../docs/toolchain.md)，人工步驟見 [README](../../../README.md)。
