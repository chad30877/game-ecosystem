# 15: 炎角獸技能池與戰鬥選擇

**What to build:** 炎角獸依個體攜帶技能，在普通近戰攻擊與兩個主動技能間形成可觀察的戰術取捨。

**Blocked by:** 14：個體技能配置與視野決策。

**Status:** ready-for-agent

- [ ] 炎角獸技能池包含烈焰衝鋒、熾熱猛擊、防禦姿態、威嚇咆哮；普通近戰攻擊不占技能名額。
- [ ] 攜帶技能可由策略分別選擇；能量、冷卻、施放中限制遵循任務 14，不合法時不自動換招。
- [ ] 威嚇咆哮造成短距離範圍移動偏向干擾敵方，不造成傷害、不封鎖攻擊；具體強度與持續時間於可遊玩原型調整。
- [ ] 攻擊與效果不傷害同物種友軍；技能結果由世界狀態及事件呈現，可見與無畫面執行一致。
- [ ] 沿用世界執行入口及人工操作核對技能選擇與效果；不新增測試檔。
