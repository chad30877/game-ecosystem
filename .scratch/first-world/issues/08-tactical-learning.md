# 08：三物種戰術學習與連續訓練

**Status:** ready-for-agent

**What to build:** 讓三物種在完整世界依視野資訊、個體技能配置與生存目標學習戰術，並能於每輪結束後保留策略繼續訓練。

**Blocked by:** 02：三物種共享策略與動態個體驗證；06：霜羽獸遠程牽制與近戰對抗；07：苔靈培育與護盾生存；14：個體技能配置與視野決策；15：炎角獸技能池與戰鬥選擇；16：霜羽獸技能池與遠程控制；17：苔靈技能池與生態／區域控制。

## 驗收條件

- [ ] 模型不取得全圖即時情報；視野輸入、轉向與技能決策符合正式規格，輸出涵蓋移動、瞄準、攻擊、技能及採食，同種共用策略而個體能依觀察採取不同動作。
- [ ] 策略在不施放、技能欄位 1／2 之間選擇；能量不足、冷卻中或施放中不會由世界暗中改選，允許追擊失誤、撤退失誤及無效嘗試。
- [ ] 三物種策略各一套，不因技能配置不同立即拆策略；生存與成功繁殖是主要目標，不直接獎勵傷害或擊殺；獎勵與探索配置可追溯。
- [ ] 每物種不同配置的初始及訓練個體盡量均衡涵蓋；可依配置觀察表現，且訓練期間個體新增或移除不會錯配策略。
- [ ] 正常觀看與無畫面均可訓練；每輪到時或全滅後保留策略並重建三物種，輸出訓練步數與各物種統計。

## 驗證方式

沿用規格提出的世界執行入口，固定種子與配置核對觀察、動作、事件及輪次結果；保留並執行屆時存在的有效測試。本任務不授權新增測試檔，若需要新增須先取得使用者同意。
