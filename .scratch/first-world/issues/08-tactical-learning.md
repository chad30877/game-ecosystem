# 08：三物種戰術學習與連續訓練

**Status:** ready-for-agent

**What to build:** 讓三物種在完整世界依局部感知學習戰術動作，並在每輪結束後保留策略繼續。

**Blocked by:** 02：三物種共享策略與動態個體驗證；06：霜羽獸遠程牽制與近戰對抗；07：苔靈培育與護盾生存。

## 驗收條件

- [ ] 模型輸入不包含全圖即時情報；輸出涵蓋移動、瞄準、攻擊、施法與採食，同種共享策略但個體可採不同動作。
- [ ] 世界執行動作結果，允許無效嘗試、追過遠及撤退失誤；硬性限制只守住能力、能量及冷卻規則。
- [ ] 生存與成功繁殖是主要目標，不直接獎勵擊殺或傷害；獎勵、探索配置與變更均可追溯。
- [ ] 正常觀看與無畫面均可訓練；每輪到時或全滅後保留策略並重建三物種，輸出訓練步數與各物種統計。

## 驗證方式

沿用規格提出的世界執行入口，核對可觀察結果並提供人工操作步驟；保留及執行屆時存在的有效測試。本任務不授權新增測試檔，若需要新增須先取得使用者同意。
