# 生存資源與 Environment 任務索引

[正式規格](spec.md)已由使用者確認並發佈為 ready-for-agent。01–06 已完成並標記 resolved，07 尚未啟動；逐張任務是狀態與依賴的維護來源。ready-for-agent 表示內容就緒，所有前置 resolved 後才能開始。

已依 to-spec 與 to-tickets 原地整理：規格補齊問題、解法、53項使用情境、實作決策、驗證決策與範圍；沿用既有七張拆分及依賴，每張補齊可獨立觀察的完整交付路徑。

本輪以 Environment 與規則式 AI 為主，PPO 訓練及混合控制實驗延後。舊[資源動態化與主動探索](../dynamic-resources-and-exploration/README.md)的 01–06 為已交付基礎；舊 07 學習成效驗收已延後為 deferred，保留未完成狀態與證據，不是本輪前置，也不由本輪結果替代。

## 依賴與執行

- 01 建立資源結算；02 接入走跑、技能及繁殖。03 補隔離入口，04 補共同採食觀察與規則決策，兩者都依賴 02。
- 05 記錄 04 的行為與四資源歷史；06 同時需要 03 的隔離入口與 05 的可追溯證據；07 在 06 基本生存通過後才開始。
- 01、02、04 各自交付所需的簡潔畫面與對外紀錄，不等待 05；05 的獨立交付是死亡前因追溯。03 的隔離開關紀錄由 06 整合核對，不增加 05 對 03 的不必要依賴。
- 依既有程式調查，沒有必要另開廣泛前置重構。必要局部整理在各切片內先做，各切片完成後可建置並由正式入口展示；01 的短期成本適配於 02 完成遷移。
- 01–05 已實作並 resolved；06／07 尚未啟動，維持 ready-for-agent。本次不宣稱完整規格的生存矩陣與生態觀察已完成。每次實作完成建立繁體中文 commit，將驗證及人工操作寫入逐張任務。
- 保留並執行既有有效檢查，透過正式世界入口及執行產物驗證，不新增測試檔；確有需要時另依專案規範取得同意。

## 完成界線

四資源規則正確、30 場單體基本生存通過、完成分階段生態觀察及診斷，即可評估本輪完成。規則違反須修正，生態偏差連結證據列入後續構想，不宣稱環境已全面完善。

人工核對：先開啟規格參數表與完成標準，再依前置順序查看任務驗收；實作後用各任務記錄的命令及回放重現結果。[訪談背景](../../docs/design/survival-resources-and-environment.md)與[延後構想](../../docs/future-ideas.md)供查閱。
