# 01：四項資源與雙路徑恢復

**What to build:** 以四項資源取代共用能量，從既有世界入口觀察消耗、進食、恢復與飢餓傷害；所有世界控制方式使用同一套結算。

**User stories:** 01–15。

**Blocked by:** 無；承接舊功能已完成的 01–06，舊 07 學習驗收不是前置。

**Status:** ready-for-agent

[正式規格](../spec.md)為實作依據。開始前讀取前置完成紀錄與本任務討論；前置全部 resolved 才能開始，開始改 claimed，全部驗收通過才改 resolved。

## 驗收條件

- [ ] 四資源上限、初始值及完整配置符合規格；無第五項重複能量，無負值或超上限。
- [ ] 自動恢復與營養恢復可並行；脫戰／休息等待、30% 啟動／60% 停止、暫停及飽食度底線可從狀態核對。
- [ ] 健康20%、體力40%且同時符合營養恢復時，以2：1分配營養支出；覆蓋某項暫停、達目標與營養不足，未轉換部分不扣費。
- [ ] 飽食度歸零停止健康兩條恢復路徑並按時間扣健康；體力／魔力仍可自動恢復，死亡不被後續回血復活。
- [ ] 用固定配置與指定動作核對基礎消耗、食物收入、兩類恢復與資源上下限，保存可重現的狀態／事件證據。
- [ ] 本切片即可從既有配置設定四資源初值，於個體檢視看到四項數值、恢復狀態與基本收支；不用等待單體隔離或完整死亡診斷才能展示。
- [ ] 共同資料與必要介面能建置，版本明確區分新舊語意；不執行PPO訓練，不新增測試檔。

## 人工核對

以既有世界入口設定低健康、體力與魔力，觀察兩條恢復、飽食度支出及底線；停用採食觀察飢餓停止回血。
