# 05：四資源觀察、死亡前因與回放

**What to build:** 即時畫面、規則運行紀錄、摘要與回放一致呈現資源收支、決策及死亡過程，能追查多種因素造成的生存失敗。

## 驗收條件

- [ ] 個體檢視簡潔顯示四資源、走跑、恢復啟停／暫停及行為理由；不把規劃中的能力寫成既有成果。
- [ ] 資源帳分列基礎、活動、技能、繁殖、進食及兩條恢復；期初、收入、支出、期末可核對，不重複計算營養轉換。
- [ ] 死亡紀錄能關聯死亡前資源變化、戰鬥／飢餓傷害、最近進食、繁殖與恢復，保留最後死因及混合成因證據。
- [ ] 分開起始成年／新生、觀察存活秒數／生命年齡及未完成生命；不能把存活到截止者當作完整壽命。
- [ ] 規則模式可產生可回放結果，前後拖動能重現資源、決策及死亡；不需PPO模型、不重新執行策略。
- [ ] 全景與個體當時所知可區分，配置、種子、版本及隔離開關可追溯；保留舊資料並明確處理版本不相容。
- [ ] 同步適用的使用文件與人工操作，完成相關建置、回放與紀錄核對；不新增測試檔。

## 人工核對

選取個體觀察恢復及爭食理由，回放跨越一次繁殖與死亡並前後拖動；對照資源帳、最後死因與死亡前歷史。
