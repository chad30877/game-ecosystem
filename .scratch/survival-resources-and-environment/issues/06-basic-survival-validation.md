# 06：三物種單體基本生存驗收

**What to build:** 透過正式世界入口完成30場可重現單體規則生存驗收，以實際補給證據確認四資源環境能維持基本生存。

**Blocked by:** [03：單體與生命週期隔離入口](03-isolated-scenarios.md)、[05：四資源觀察、死亡前因與回放](05-observation-and-diagnostics.md)

**Status:** ready-for-agent

[正式規格](../spec.md)為實作依據。開始前讀取前置完成紀錄與本任務討論；前置全部 resolved 才能開始，開始改 claimed，全部驗收通過才改 resolved。

## 驗收條件

- [ ] 每物種各種子101–110、每場600模擬秒，共30場；單一成年個體、無敵人、停用繁殖與老化，使用規則AI。
- [ ] 保存起始配置、可達食物佈局、供給參數與實際供給證據；不以瞬間補滿、AI特權或反覆重建撐過時間。
- [ ] 全部存活至結束且飢餓健康損失為零；記錄最低飽食度、進食量、恢復量與營養支出，證明不是只靠初始儲備。
- [ ] 報告列出每場結果與失敗，不挑種子；若校準，保存前後數值、理由並重跑受影響的完整矩陣，不放寬驗收門檻。
- [ ] 每物種保留可人工檢視的代表回放，固定配置的可見與無畫面遵守相同規則。
- [ ] 全部門檻通過才標記resolved；未通過時維持未完成並記錄原因，不以能啟動替代生存驗收，不新增測試檔。

## 人工核對

開啟30場結果表，核對每場600秒、存活及零飢餓傷害；播放三物種代表紀錄，確認正常進食與資源恢復。
