# 02：走跑、技能與繁殖成本拆分

**What to build:** 讓走路、奔跑、攻擊、技能及繁殖支付正確資源，保留體力耗盡時的自救能力與親代生存儲備。

## 驗收條件

- [ ] 明確走路／奔跑動作可由手動、指定動作及控制介面使用；跑速1.5倍、每秒耗10體力，不足降為走路且仍可採食。
- [ ] 普通近戰只扣體力，基本冰箭及十二種特殊技能只扣魔力；成本數字依規格，烈焰衝鋒與熾熱猛擊無複合扣費。
- [ ] 既有技能效果、冷卻、前搖及無效輸入語意保留；技能固定速度不疊乘跑速，劇烈活動與攻擊正確重設恢復等待。
- [ ] 健康80%、飽食度80等繁殖門檻、親代扣40及扣後底線成立；人口滿額、未成年、冷卻或資源不足不得出生或扣費。
- [ ] 新生飽食度30獨立於世界初始60，所得不超過親代支出；成年年齡30及壽命240保留，幼體能力不新增差異。
- [ ] 透過現有技能與生命週期驗證入口核對成功、低資源及無效情境，保存證據與相關建置結果；不新增測試檔。

## 人工核對

連續奔跑至體力耗盡，再走路採食與休息；分別施放近戰、冰箭及特殊技能核對扣費，觀察一次繁殖前後親子資源。
