# 04：可見採食與爭食、換點決策

**What to build:** 規則 AI 透過共同局部觀察辨識食物競爭，依自身狀態與已知替代來源選擇爭食、換點、休息或撤退。

**User stories:** 26–37。

**Blocked by:** [02：走跑、技能與繁殖成本拆分](02-activity-and-reproduction.md)

**Status:** resolved

[正式規格](../spec.md)為實作依據。開始前讀取前置完成紀錄與本任務討論；前置全部 resolved 才能開始，開始改 claimed，全部驗收通過才改 resolved。

## 驗收條件

- [x] 新增實際可見的採食狀態與來源關聯；明確區分當前可見、記憶與未知，不增加全域追蹤識別碼、內在目標或隱藏戰力。
- [x] 資訊來自已結算且合法可見的行為；視野外不讀取全域ate事件更新，不能預知當步尚未結算的採食。
- [x] 規則與未來策略介面共享合法資訊與走跑動作；相容性簽章更新並拒絕不相容模型，不執行PPO訓練或混合實驗。
- [x] 食物目標與競爭者連動，低飽食度不一律禁攻；缺替代且有能力時可爭食，有替代且自身狀況差時換點，代價升高時重選。
- [x] 敵方離開、自己可取得足夠食物或來源耗盡後終止該次爭奪；未知來源需探索，舊記憶撲空後更新，不無限追殺或無意義切換。
- [x] 依物種與攜帶技能選擇手段，苔靈不使用不存在的普通攻擊，定身不被當成停止敵方採食；保留合理定居與基本掃視。
- [x] 記錄判斷門檻初值、目標與決策理由，以唯一來源爭食、安全替代、撤退、來源枯竭及視野內外情境核對；保存證據，不新增測試檔。
- [x] 可見世界當場顯示簡短決策理由，紀錄可追溯合法採食訊號到目標選擇及實際動作；不將觀察欄位與行為接入拆成無法獨立展示的半成品。

## 人工核對

觀察敵方採食目標來源時的爭食，再以低健康及已知替代來源觀察換點；將競爭者移出視野，核對個體不再取得即時採食資訊。

## 完成紀錄

- 2026-10-23：加入已結算採食 feeding 與來源座標；共同 EntityObservation 僅在敵方及來源合法可見時提供採食關聯，視野外警戒記憶不攜帶採食旗標或來源。不新增策略用追蹤識別碼，不讀全域 ate 事件。
- ObserveEntities 由7維改10維，新增採食旗標及與食物列同座標系的來源相對位置；非生物及不可見列相應欄位為0。版本 survival-v8，Runner、bridge、模型相容性、重載及回放同步更新。run控制方式與規則物種名單記於執行標頭。
- 規則只將目標來源的實際採食競爭者納入爭食；低飽食不禁攻，有安全替代且弱勢時換點、損失過高撤退；自己取得足夠採食或來源消失後停止爭奪。保留有限記憶、舊情報撲空後探索、定居及掃視，技能只來自攜帶配置。低體力走路，跑步使用60啟動／20停止的獨立偏好。
