# 03：單體與生命週期隔離入口

**What to build:** 擴充既有世界執行入口，真正支援指定物種的單一成年個體，以及獨立停用繁殖與老化，供基本生存及成本校準使用。

**Blocked by:** [02：走跑、技能與繁殖成本拆分](02-activity-and-reproduction.md)

**Status:** ready-for-agent

[正式規格](../spec.md)為實作依據。開始前讀取前置完成紀錄與本任務討論；前置全部 resolved 才能開始，開始改 claimed，全部驗收通過才改 resolved。

## 驗收條件

- [ ] 可只產生指定物種的一名成年個體，不暗中補入其他物種或個體。
- [ ] 繁殖及老化有獨立、可記錄的顯式驗證設定；不是透過極大壽命、人口上限或反覆重建達成。
- [ ] 未啟用隔離設定時保留正常生命週期；配置、種子、步長與特殊開關完整寫入執行產物。
- [ ] 可從既有配置／指定動作入口設定四資源及食物位置、存量與供給，600秒觀察不被既有短輪次設定截斷。
- [ ] 提供可重現的充足供給佈局及理由，透過正常食物生命週期與採食滿足需求，AI不取得特權情報。
- [ ] 以短程隔離與正常世界對照核對入口及開關，保存產物及人工操作命令；不新增測試檔或私有入口。

## 人工核對

分別啟動三個物種的單體場景，確認僅有一名個體，年齡及出生事件符合停用設定；再啟用正常生命週期確認恢復。
