# 05：親代餵養與營養收支

**What to build:** 親代透過共同世界動作餵養自己的幼體，規則 AI 能依需要選擇目標並支付營養；觀察者可追查轉移、行為互斥及中斷。

**Blocked by:** [04：親子觀察、記憶與失聯搜尋](04-family-memory-and-search.md)。

**Status:** resolved

## 驗收條件

- [x] 僅親代可對自己成長期子女開始餵養，開始需可見、距離不超過 0.7；控制者需持續選擇，短暫轉身但距離仍合法可繼續。其他關係、成年、死亡、無效目標與超距不應轉移營養。
- [x] 每模擬秒最多轉移 5 飽食度，親代扣減與子代實得為 1：1，親代餵養後不低於 30、子代不超上限；不扣除無法交付的量，記錄足以核對收支，數值可調。
- [x] 規則 AI 在可見子女低於 40 時可開始，達 60、保留量或不能繼續時停止；開始後跨過 40 不立刻停止，多名需要餵養者按最低飽食度、相同選最近。40／60 僅限制規則 AI，而非全部控制方式。
- [x] 餵養時雙方不自行採食，雙方可移動、超距中斷；親代攻擊或施法前中斷，幼體可自衛；親代受攻擊或眼前威脅可觸發規則 AI 重新決策，已轉移量保留。
- [x] 子女成年、控制者停止、資源耗盡或任一方死亡時停止；檢查近上限、時間步、部分轉移及同時動作不重複扣費、產生營養或超過限制。
- [x] 正式入口可指定並觀察行為，世界動作及合法觀察供不同控制方式使用；個體檢視、事件、資源帳及回放清楚呈現餵養及中斷，版本相容性明確。
- [x] 執行既有資源、生命循環、指定動作、bridge 與回放有效檢查；記錄固定場景及人工核對，不新增未經核准的測試檔。

## 完成紀錄


- 2026-10-28：以正式世界入口、固定種子 1 與 `artifacts/juvenile-feeding-20261028/` 的配置驗證。舊版紅燈 1 秒僅發生基礎消耗；新版親代付出 5、幼體取得 5，資源帳殘差僅浮點誤差。近保留量與近上限僅轉移可交付量；不可見、非親代、超距、親代攻擊不轉移，停止控制、幼體成年及親子任一方戰鬥死亡同一步停止。
- 雙方同時選擇採食仍只發生餵養；幼體攻擊不阻斷，雙方移動超距中止，親代轉身離開視野但未超距仍持續。多名子女先選較低飽食度，相同選最近，已開始餵養則維持到停止條件；隔離場景以可調每秒 100 點加速，低於 40 開始、跨過 40 持續，超過 60 後停止。
- Unity 建置、Python bridge、v11 舊回放及 v12 回放前後跳轉通過；v12 區分新動作與模型資料。固定配置、事件、回放與建置日誌保存在上述 artifacts 路徑（不納入 Git）。
