# 05：親代餵養與營養收支

**What to build:** 親代透過共同世界動作餵養自己的幼體，規則 AI 能依需要選擇目標並支付營養；觀察者可追查轉移、行為互斥及中斷。

**Blocked by:** [04：親子觀察、記憶與失聯搜尋](04-family-memory-and-search.md)。

**Status:** ready-for-agent

## 驗收條件

- [ ] 僅親代可對自己成長期子女開始餵養，開始需可見、距離不超過 0.7；控制者需持續選擇，短暫轉身但距離仍合法可繼續。其他關係、成年、死亡、無效目標與超距不應轉移營養。
- [ ] 每模擬秒最多轉移 5 飽食度，親代扣減與子代實得為 1：1，親代餵養後不低於 30、子代不超上限；不扣除無法交付的量，記錄足以核對收支，數值可調。
- [ ] 規則 AI 在可見子女低於 40 時可開始，達 60、保留量或不能繼續時停止；開始後跨過 40 不立刻停止，多名需要餵養者按最低飽食度、相同選最近。40／60 僅限制規則 AI，而非全部控制方式。
- [ ] 餵養時雙方不自行採食，雙方可移動、超距中斷；親代攻擊或施法前中斷，幼體可自衛；親代受攻擊或眼前威脅可觸發規則 AI 重新決策，已轉移量保留。
- [ ] 子女成年、控制者停止、資源耗盡或任一方死亡時停止；檢查近上限、時間步、部分轉移及同時動作不重複扣費、產生營養或超過限制。
- [ ] 正式入口可指定並觀察行為，世界動作及合法觀察供不同控制方式使用；個體檢視、事件、資源帳及回放清楚呈現餵養及中斷，版本相容性明確。
- [ ] 執行既有資源、生命循環、指定動作、bridge 與回放有效檢查；記錄固定場景及人工核對，不新增未經核准的測試檔。
