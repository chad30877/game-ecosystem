# 04：親子觀察、記憶與失聯搜尋

**What to build:** 親代能辨識並持續記住自己的子女，依最後觀察與時間推測幼體成長及營養；需要時找尋最後位置，幼體空閒時可靠近可見親代。

**Blocked by:** [01：幼體成長與普通攻擊](01-growth-and-basic-combat.md)。

**Status:** ready-for-agent

## 驗收條件

- [ ] 實際出生建立正確親子關係；親代存活期間記住子女，能在可見時辨識自己的子女、飽食度及成長階段；其他個體不自動收養或接手。
- [ ] 看不見子女時只保留最後觀察及時間，不得取得即時位置、飽食度或視野外生死；依已知年齡及有效老化時間推測成年，推測成年後停止主動養育。
- [ ] 推測幼體飽食度為最後觀察值減經過時間的基本消耗，最低 0；不以推測歸零宣稱死亡，重見後以實際觀察修正。預設基本消耗每秒 0.5，可調。
- [ ] 無更緊急生存需求時，對推測飽食度低於 40 或最後看到正受威脅的失聯幼體，可前往最後位置；找不到後恢復自身生活，不立即反覆搜尋同一舊位置，重見後更新。
- [ ] 親眼看見子女死亡時記住死亡並停止尋找；視野外死亡不直接告知。親代不為陪伴主動靠近；幼體無緊急需求時傾向靠近可見親代，可自行離開求生。
- [ ] 使用正式入口重現出生、失聯、成年推測、可見／不可見死亡、舊位置搜尋與重見；共同觀察、精簡個體檢視及回放區分最後觀察、推測與真值，版本相容性明確。
- [ ] 保留既有生命循環、局部感知及記憶有效檢查，記錄人工核對方式，不新增未經核准的測試檔。
