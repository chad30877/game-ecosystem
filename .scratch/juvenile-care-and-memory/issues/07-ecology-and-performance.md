# 07：生態對照與效能驗證

**What to build:** 使用者取得可重現的有無養育多種子對照與記憶推測效能報告，理解親代和幼體的生存、代價，以及完整新機制的限制。

**Blocked by:** [02：隨成長變化的技能](02-growing-skills.md)、[03：食物記憶推測與回訪](03-food-memory-prediction.md)、[06：親代保護與生存取捨](06-parent-protection.md)。

**Status:** ready-for-agent

## 驗收條件

- [ ] 以多組固定種子比較有無養育；兩組保持相同初始配置、幼體成長規則及種子，只切換養育行為，記錄樣本數、時間及後續行為分歧造成的限制。
- [ ] 分物種記錄親代及幼體存活、雙方死亡、未完成生命、餵養資源收支、保護及食物供給；區分直接觀察、推測與未確認因果，不預設養育必然改善生存或完整生態平衡。
- [ ] 包含食物充足、供給有限及可見威脅情境，核對親代自行覓食、幼體自行求生、餵養／保護代價及失聯推測；保留失敗和代表回放，不只挑選成功場次。
- [ ] 以相同配置量測推測功能前後的模擬速度，包含較多個體與記憶，記錄個體數、記憶規模、步長、控制方式、輸出與執行環境；若成本明顯增加追查瓶頸，避免把估算或未控因素當成確切效能結論。
- [ ] 統合核對技能跨成年、共同培育、親子觀察、餵養中斷、保護終止、記憶真值邊界、可見與無畫面規則及回放前後跳轉；不相容資料明確提示，保留相容舊回放。
- [ ] 沿用正式入口及既有有效建置、bridge、生命循環、技能、保存及回放檢查；規則違反需修正並重驗受影響情境，觀察到的生態偏差連結證據列為後續構想。
- [ ] 記錄實際配置、命令、結果、效能、限制及人工回放方式；不執行 PPO、混合控制或果實機制，不新增未經核准的測試檔。
