# 06：親代保護與生存取捨

**What to build:** 親代規則 AI 依可見幼體、異種威脅及自身狀態選擇介入或撤退；觀察者能看到保護代價、與餵養的切換及各物種不同手段。

**Blocked by:** [05：親代餵養與營養收支](05-parent-feeding.md)。

**Status:** resolved

## 驗收條件

- [x] 親代同時看見自己的幼體與距幼體 2.5 以內的異種時，可在幼體受傷前評估保護；不可依視野外真值定位威脅或子女，警戒距離可調。
- [x] 健康低於自身上限 45% 時不主動為保護接戰；低於 25% 或介入後損失上限 20% 健康時優先撤退。威脅離開幼體附近、親代看不見威脅或幼體安全離開時結束保護，不無限追擊；門檻可調。
- [x] 多名子女受可見威脅時先評估最近者；自身立即危險、幼體保護、親代緊急補給及餵養按確認的優先順序重新評估，且不因陪伴強迫親代放棄自身一般覓食。
- [x] 炎角、霜羽、苔靈依自身普通攻擊及攜帶技能採取可用手段，不新增苔靈普通攻擊或特殊獵殺幼體行為；幼體仍可在既有爭食或自衛中受傷。
- [x] 餵養中出現可見威脅或親代遭攻擊時，規則 AI 可中斷餵養、評估保護或撤退；已支付及接收的營養保留，幼體可自行逃跑或自衛。
- [x] 正式入口可重現保護成功、失敗、親代撤退及親代／幼體死亡；事件、個體檢視與回放呈現可見依據、選擇及結果，不將預期勝負作世界真值提供策略。
- [x] 保留既有爭食、戰鬥、視野、餵養及回放有效檢查；記錄固定配置、人工核對及限制，不新增未經核准的測試檔。
