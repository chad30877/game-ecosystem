# 03：食物記憶推測與回訪

**What to build:** 生物根據自己最後看見的食物狀態與時間，推測休養、恢復中或未成熟來源可能已可採食；缺少較可靠食物時回訪，並依重新觀察修正。

**Blocked by:** 無。

**Status:** ready-for-agent

## 驗收條件

- [ ] 對最後看見為休養、恢復中或未成熟的食物，以可調 30 模擬秒概略等待推測可能可採食，不估算視野外現有存量或讀取真實剩餘時間、被採食及存在狀態。
- [ ] 缺少較可靠可採食來源時可將推測位置列為探索目標；危險與眼前可靠食物可優先，未達估計時間不把推測當作已觀察真值。
- [ ] 回訪仍休養時更新觀察並重新等待；來源已消失且位置重新可見時撤銷記憶；不對同一已確認舊情報立刻反覆折返。更新後照實選擇可採食、探索或其他生存行動。
- [ ] 沿用方向視野、有限食物／區域記憶與掃視，不讓規則 AI 或未來策略取得視野外真值；共同觀察可辨最後觀察與推測，執行記錄及回放可與世界真值對照。
- [ ] 透過正式入口及固定動作重現食物視野外恢復、被吃掉、消失及推測錯誤，涵蓋重新觀察和生存優先；資料版本識別正確、相容舊回放保留、不相容資料明確提示。
- [ ] 保留既有記憶、掃視、來源週期、bridge 及回放有效檢查，記錄可見人工重現方式，不新增未經核准的測試檔。
