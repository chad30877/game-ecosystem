# 02：隨成長變化的技能

**What to build:** 使用者可在既有技能場景看見幼體攜帶技能隨成長變強，施放後的效果維持當時比例，並觀察多名苔靈共同培育的實際產量。

**Blocked by:** [01：幼體成長與普通攻擊](01-growth-and-basic-combat.md)。

**Status:** ready-for-agent

## 驗收條件

- [ ] 炎角衝鋒距離／傷害、熾熱猛擊傷害、防禦減傷幅度、咆哮偏向強度／持續時間依比例成長；防禦不能錯誤地因縮放承受傷害倍率而變強。
- [ ] 霜羽霜縛箭傷害／減速時間、穿透冰矢傷害、寒霧遁行距離、陷阱定身／減速時間依比例成長；苔靈培育速率、根鬚定身時間、煙幕範圍依比例成長。
- [ ] 播種維持成體效果，煙幕偏向強度與中毒傷害不縮放；未列項目的費用、冷卻、範圍、速度與持續效果維持既有規則，無效動作不重複扣費。
- [ ] 每次技能固定起手比例；核對前搖、投射物命中、跨成年及持續效果。施法者死亡後效果是否繼續沿用既有規則，若繼續不重算比例。
- [ ] 同一來源的多個培育不疊加，採當下最強有效且依各自起手比例固定的速率；強效果結束或失效後仍有效的次強效果接續，容量、成熟與休養限制仍生效。
- [ ] 規則 AI 依自身有效技能能力選擇，三物種既有能力、有效檢查及共同控制契約保留；正式入口、簡潔觀察、回放及版本呈現必要結果。
- [ ] 固定場景對照出生、成長中、成年與跨時點效果，保留事件、配置及人工核對方式；不新增未經核准的測試檔。
