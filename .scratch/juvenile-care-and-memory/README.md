# 幼體成長、親代養育與記憶推測任務索引

[正式規格](spec.md)及以下七張任務已依使用者確認的驗證入口、拆分及依賴發佈。逐張任務是狀態與前置的維護來源；標記 ready-for-agent 僅表示內容就緒，所有前置 resolved 才能開始，開始時改 claimed、全部驗收後改 resolved。

| 編號 | 任務 | 前置 | 可獨立驗證的結果 |
| --- | --- | --- | --- |
| 01 | [幼體成長與普通攻擊](issues/01-growth-and-basic-combat.md) | 無 | 新生幼體健康上限及普通攻擊隨年齡變化，恢復與生命階段可觀察。 |
| 02 | [隨成長變化的技能](issues/02-growing-skills.md) | 01 | 三物種指定技能依施放時成長程度產生效果，共同培育取最強有效效果。 |
| 03 | [食物記憶推測與回訪](issues/03-food-memory-prediction.md) | 無 | 依舊情報推測可能恢復，回訪並以觀察修正。 |
| 04 | [親子觀察、記憶與失聯搜尋](issues/04-family-memory-and-search.md) | 01 | 親代記住子女、依局部資訊及推測尋找失聯幼體，幼體可靠近可見親代。 |
| 05 | [親代餵養與營養收支](issues/05-parent-feeding.md) | 04 | 親代以共同動作餵養幼體，營養轉移、停止及行為互斥可核對。 |
| 06 | [親代保護與生存取捨](issues/06-parent-protection.md) | 05 | 親代依可見威脅、能力與自身狀況選擇保護或撤退，保護與餵養的切換可核對。 |
| 07 | [生態對照與效能驗證](issues/07-ecology-and-performance.md) | 02、03、06 | 多種子比較有無養育，量測記憶推測成本，保存整合觀察與限制。 |

## 依賴與執行

- 01 建立成長比例與當前健康上限，供技能及親子生命階段使用；02、04 均需 01。03 可由既有食物與記憶獨立交付，不依賴養育。
- 05 需 04 的親子關係及可見資訊；06 需 05 的餵養中斷及決策優先順序。06 可驗證成年親代的保護，不因幼體技能縮放而新增對 02 的前置；最終 07 同時覆蓋 02、03、06 的完整整合。
- 任務依賴不代表授權啟動平行 agent。每張交付其必要的共同世界動作／狀態、簡潔觀察、資料版本及外部行為驗證，不能將基礎觀察或回放全部留到 07。
- 局部調整併入可驗證切片；若發現無法保持建置或外部契約的廣泛重構，先評估展開與收斂的拆分，不預設另開廣泛重構任務。
- 沿用正式世界入口、固定配置與指定動作；保留既有有效檢查，不新增測試檔，確有具體必要時依專案規範先取得同意。每次改動完成提交繁體中文 commit，並記錄人工測試方式。
- 本輪不執行 PPO 或果實機制，不恢復舊 deferred 學習驗收。初值、效能與生存改善均待實測；結果不當作完整生態平衡。

人工核對：依前置順序開啟規格與各任務，確認每張都有可觀察交付、驗收及依賴；實作後以任務完成紀錄的配置、固定種子與回放重現。
